# 焊缝连续三维管道显示设计

## 目标

提高 CAD 窗口中焊缝在斜视和缩放状态下的可见性，同时保持焊缝中心线数据精确不变，为后续 CAD 焊缝到扫描点云的坐标映射保留可靠输入。

## 本次范围

- 将当前按屏幕像素绘制的绿色线段改为具有模型空间直径的连续三维管道。
- 管道遵守正常深度测试，被 CAD 模型遮挡的部分不穿透显示。
- 支持现有焊缝创建、显示和删除流程。
- 暂不实现焊缝到点云窗口的映射。

## 数据边界

`WeldSeamData.points` 和 `WeldSeamData.segments` 继续表示真实焊缝中心线。显示管道只由 `VisualizationManager` 临时生成，不写回焊缝数据，也不参与长度、配准、映射或轨迹计算。

## 渲染设计

1. `VisualizationManager::showSeam` 将一条焊缝的所有中心线段转换为一个 `vtkPolyData`，每条焊缝只维护一个显示 Actor。
2. 使用 `vtkTubeFilter` 围绕中心线生成圆形截面管道，开启端帽，截面边数使用 12，以兼顾平滑度和渲染成本。
3. 管道直径取当前 CAD 包围盒对角线的 `0.5%`。当对角线不可用时，根据焊缝包围盒或焊缝长度计算回退尺度。
4. 管道使用高亮绿色，保持不透明，并使用正常深度测试。
5. Actor ID 沿用焊缝 ID，删除焊缝时一次删除整个管道 Actor。

## 状态与生命周期

- `showCadModel` 保存当前 CAD 对角线，供焊缝显示尺寸计算。
- 创建焊缝时生成管道 Actor。
- 删除焊缝时释放对应 Actor。
- 重新导入 CAD 时 `removeAllShapes` 清除旧焊缝，现有焊缝数据清理由主窗口负责。

## 异常处理

- 空焊缝或零长度线段不创建管道。
- 非有限坐标跳过，避免 VTK 管线异常。
- 如果所有线段均无效，函数安全返回，不影响主窗口。
- 管径设置最小正值，避免零尺度模型产生无效几何。

## 验证标准

- Release x64 项目编译通过，Qt MOC 和 VTK 链接正常。
- 新建焊缝后只生成一个管道 Actor，绿色管道明显粗于当前线段。
- 旋转模型时，管道保持三维直径并遵守模型遮挡。
- 删除焊缝后对应管道完全消失。
- 焊缝中心线点、线段数量和长度计算结果不发生变化。
