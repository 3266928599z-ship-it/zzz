# 故障排查手册

## 1. 排查原则

遇到问题时按以下顺序：

1. 保留错误截图和完整日志；
2. 记录 Git 提交、配置、输入文件和操作步骤；
3. 先判断是环境、输入、线程、算法还是显示问题；
4. 使用相同文件重复一次；
5. 不要在原因未知时同时修改多个阈值；
6. 修复后补充回归测试。

## 2. Visual Studio 项目显示“已卸载”

可能原因：

- Qt VS Tools 未安装；
- Qt 版本名称无法解析；
- `.vcxproj` XML 错误；
- 文件被重复加入多个项目；
- 依赖路径或导入文件不存在。

处理：

1. 右键项目，选择“重新加载项目”；
2. 阅读弹窗中的第一个具体错误；
3. 检查 Qt VS Tools；
4. 检查 `QtInstall` 名称；
5. 检查 `.vcxproj` 中同一文件是否既是 `ClInclude` 又被错误添加到其他项目；
6. 若提示文件属于两个项目，确认解决方案中没有重复引用。

## 3. 找不到 `qt.targets` 或 `qt.props`

现象：

```text
QtMsBuild: could not locate qt.targets, qt.props
```

处理：

1. 安装 Qt VS Tools；
2. 在 Qt Versions 中注册 Qt；
3. 确认版本名称为 `6.10.1_msvc2022_64`；
4. 检查用户属性表；
5. 清理 `.vs` 后重新打开解决方案；
6. 命令行构建时显式传入 `/p:QtInstall=...`。

## 4. 找不到 PCL/OpenCascade/VTK/Eigen 头文件

检查：

- `VcpkgRoot`；
- `x64-windows` 是否安装；
- `AdditionalIncludeDirectories`；
- 项目实际使用的是 `E:\vcpkg-master` 还是其他目录；
- 是否残留 `Z:\vcpkg-master` 路径。

不要同时混用不兼容版本的：

- PCL 头文件与库；
- VTK Debug 与 Release；
- 不同 MSVC 工具集生成的库。

## 5. 链接错误

### 找不到 `MvCameraControl.lib`

检查：

```text
E:\MVS\Development\Libraries\win64
```

以及：

```text
AdditionalDependencies = MvCameraControl.lib
```

### 大量 PCL/VTK 未解析符号

常见原因：

- x86/x64 不一致；
- Debug/Release 库混用；
- PCL 与 VTK 版本不匹配；
- vcpkg 与独立 PCL 安装混用；
- `PCL_NO_PRECOMPILE` 或点类型设置不一致。

## 6. 程序启动提示缺少 DLL

检查输出目录和 `PATH`：

- Qt DLL；
- `platforms\qwindows.dll`；
- PCL DLL；
- VTK DLL；
- OpenCascade DLL；
- MVS DLL。

使用工具：

- Dependencies；
- Visual Studio Modules 窗口；
- `where Qt6Core.dll`；
- `where MvCameraControl.dll`。

避免把不同版本 DLL 随意复制到同一目录。

## 7. STEP 导入失败

日志：

- STEP 文件读取失败；
- 文件中没有有效实体；
- 模型尺寸无效；
- 三角化或表面采样失败。

检查：

1. 文件扩展名和内容；
2. CAD 软件能否打开；
3. 模型是否只有无效引用或空装配；
4. 单位和坐标是否合理；
5. 文件路径是否包含无法被当前 OpenCascade 路径编码处理的字符；
6. 尝试导出为标准 AP214/AP242 STEP。

## 8. CAD 显示异常或选面错误

可能原因：

- 三角化精度过低；
- `cellToFaceMap` 与网格三角形数量不一致；
- actor 覆盖了拾取；
- 未按住 Ctrl；
- 点击的是空白区域。

检查：

1. 日志是否显示 CAD 导入成功；
2. 是否点击“新建焊缝”进入选面模式；
3. 是否按住 Ctrl；
4. 是否选择两个不同面；
5. 面高亮是否分别为红色和蓝色。

## 9. 点云导入卡顿

当前文件读取已在后台执行，但仍可能出现：

- 磁盘读取慢；
- PLY 解析耗时；
- 内存不足；
- 渐进显示期间 GPU/CPU 压力；
- 数百万点创建多个 VTK actor。

判断阶段：

- 状态“正在后台加载点云”：文件读取阶段；
- 状态“正在显示完整点云 XX%”：渲染阶段；
- 日志“完整点云显示完成”：已就绪。

处理：

1. 使用 Release x64；
2. 保证足够内存；
3. 使用 SSD；
4. 等待显示完成后再匹配；
5. 若只为算法测试，可后续增加“显示降采样/算法保留全量”选项；
6. 当前需求是显示全部点，不应直接删除原始点。

## 10. 点云颜色异常

原始点云使用 `z` 字段着色，不一定使用文件中的 RGB。

若颜色范围异常：

- 检查 Z 值单位；
- 检查是否存在极端 Z 离群值；
- 检查相机 `zScale`；
- 检查点云坐标轴方向。

## 11. “模型匹配”按钮不可用

必须同时满足：

- CAD 有效；
- 点云非空；
- 完整点云显示结束；
- 没有点云后台加载；
- 没有相机采集；
- 没有正在运行的模型匹配。

重点看状态栏是否仍显示点云渲染百分比。

## 12. 预处理后点数不足

日志：

```text
预处理后有效点数不足
```

可能原因：

- 原始点云太少；
- 体素过大；
- 底板剔除误删工件；
- SOR 过严；
- 聚类只选到小碎片；
- 法向估计产生大量无效法向；
- 单位异常导致邻域尺度不合理。

排查：

1. 记录原始点数；
2. 记录 CAD 对角线和 `leaf`；
3. 临时可视化每个预处理阶段；
4. 检查聚类日志；
5. 不要直接把最低点数改为更小。

## 13. 工件聚类选错

特征：

- 显示的处理后点云是夹具或圆环；
- 尺寸比明显异常；
- 粗配准失败。

原因：

- 工件被分成多个不连通块；
- 夹具比工件点更多；
- 工件残缺后对角线小于 0.45 倍 CAD；
- 聚类距离太小；
- 底板未被剔除。

处理：

1. 检查 `ClusterTolerance = 2 * leaf`；
2. 检查底板平面比例；
3. 增加候选聚类而不是只保留一个；
4. 后续可让多个合理聚类共同进入粗配准评分；
5. 使用 CAD 引导裁剪作为第二道筛选。

## 14. 粗配准无有效候选

日志：

```text
粗配准未生成有效候选
```

优先检查：

1. CAD 和点云是否同一零件；
2. 单位是否一致；
3. 处理后点云是否为工件；
4. CAD/扫描降采样点数是否至少 100；
5. 关键点是否至少 100；
6. 特征覆盖是否过低；
7. 是否存在镜像关系。

当前算法不匹配镜像。镜像矩阵会被明确拒绝。

调参顺序：

1. 增加 `sacRuns`；
2. 适当降低 `sacInlierFrac`；
3. 增加关键点比例；
4. 检查 PPF 是否抛异常；
5. 不要先降低最终质量门槛。

## 15. 所有候选在 ICP 复核后失败

日志：

```text
所有粗配准姿态在ICP复核后均无有效对应
```

可能原因：

- 粗姿态仍太差；
- CAD 引导裁剪在 6.0 倍体素阶段保留点不足；
- 候选对齐了夹具；
- 单位错误；
- 点云缺失太严重；
- 法向方向和几何不稳定。

检查自动裁剪候选日志中的：

- 保留点数；
- 保留比例；
- 扫描覆盖；
- 特征覆盖；
- 空间覆盖；
- CAD 支持。

## 16. 精配准卡死或耗时很长

当前最大候选为 6，每个候选执行三次点到点 ICP，最佳候选再执行点到面 ICP。

处理：

1. 使用 Release；
2. 确认 OpenMP 生效；
3. 增大体素；
4. 减少粗候选数或 ICP 迭代；
5. 检查扫描聚类是否仍包含大量无关点；
6. 增加阶段计时日志；
7. 不要在 UI 线程直接调用 Worker。

## 17. 精配准崩溃

当前版本已增加：

- 最低点数；
- 非有限值检查；
- LDLT 状态检查；
- 对角阻尼；
- 旋转和平移步长限制；
- 未知异常捕获；
- 最终刚性矩阵检查。

若仍崩溃：

1. 使用 Visual Studio 捕获第一机会异常；
2. 保留输入文件；
3. 记录崩溃堆栈；
4. 检查 PCL 内部断言；
5. 检查内存是否耗尽；
6. 检查是否使用了不匹配的 PCL/VTK DLL。

## 18. 匹配完成但视觉上对不上

不要只看 RMSE。检查：

- 是否只对齐一个大平面；
- 圆弧、孔、台阶、端面是否一致；
- 空间覆盖；
- 特征覆盖；
- CAD 支持；
- 是否存在对称多解；
- 点云是否实际包含另一个零件；
- `T_final` 是否被错误取逆。

视觉检查应至少从：

- 正面；
- 侧面；
- 顶部；
- 端面；
- 特征局部；

五类视角进行。

## 19. 匹配结果为“需要人工确认”

可能触发：

- 多解歧义；
- 点到面 ICP 未收敛或发生回退；
- 扫描覆盖不足；
- CAD 支持不足；
- 特征覆盖不足；
- 空间覆盖不足；
- 法向一致不足。

日志会输出诊断指标。

此状态下焊缝映射按钮禁用是预期行为。

## 20. 焊缝创建失败

可能日志：

- 面相交计算失败；
- 两个面没有交线；
- 没有生成可用焊缝点。

检查：

1. 两个面是否真实相交；
2. 是否只是相邻但存在微小间隙；
3. 是否选择了同一面；
4. STEP 几何容差是否异常；
5. OpenCascade Section 是否生成 Edge。

对于存在间隙的设计，面求交不会自动推断焊缝，需要增加容差投影或边匹配算法。

## 21. 焊缝不明显

当前使用 VTK TubeFilter，而不是普通线宽。

管道半径：

```text
0.0025 * 模型显示尺度
```

可调整位置：

```text
VisualizationManager::showSeamTube()
```

调大后注意：

- 只影响显示，不应修改 `WeldSeamData` 几何；
- CAD 与点云视图应保持一致尺度；
- 过粗会遮挡模型边缘。

## 22. 点击焊缝列表后不同步高亮

检查：

- `currentItemChanged` 信号是否连接；
- 列表项 `Qt::UserRole` 是否保存正确 ID；
- CAD actor ID 是否为 `seam_tube_<id>`；
- 点云 actor ID 是否为 `mapped_seam_tube_<id>`；
- 映射焊缝是否已创建；
- Viewer 是否在主线程更新。

当前设计不需要分别点击两个视图。

## 23. 焊缝映射按钮不可用

必须满足：

- 选中列表项；
- 最新匹配 `success == true`；
- `verdict == Pass`；
- 没有加载、采集或匹配任务。

导入新 CAD 或点云后旧匹配失效，必须重新匹配。

## 24. 映射焊缝离点云表面有偏差

原因可能是：

- 模型匹配误差；
- 相机标定误差；
- CAD 与实物制造偏差；
- 扫描缺失；
- 焊缝本身位于不可见区域；
- 当前算法仅做刚性映射，不吸附最近点。

不能简单把每个焊缝点独立吸附到最近扫描点，否则会：

- 跳到错误表面；
- 破坏连续性；
- 缩短或拉长焊缝；
- 在缺失区域产生断裂。

推荐后续使用带连续性、CAD 曲面和距离门槛的受约束投影。

## 25. 相机无法连接

检查：

1. MVS Viewer 是否占用相机；
2. 驱动是否安装；
3. GigE 网卡 IP；
4. USB 权限与带宽；
5. SDK DLL；
6. 是否检测到设备；
7. 日志错误码；
8. 是否连接了多个设备但程序只使用第一个。

## 26. 相机提示像素格式不支持

当前只接受：

```text
0x022000BB
```

处理：

- 在 MVS 中检查设备输出格式；
- 查设备 SDK 文档；
- 不要仅删除检查；
- 为新格式增加明确解析分支和帧长度计算；
- 使用真实帧建立测试数据。

## 27. 相机点云尺度或方向错误

检查：

```text
xRes
yRes
zScale
rawX 中心偏移
Y 轴运动方向
相机安装方向
```

当前 `runSpeed` 没有参与坐标计算。若 `yRes` 不是设备直接给出的每行距离，应结合触发频率和运动速度重新推导 Y。

## 28. 日志太多

当前已减少焊缝列表切换等低价值日志。

进一步改进：

- 日志等级：Info/Warning/Error/Debug；
- UI 默认只显示 Info 以上；
- 详细候选报告仅在非 Pass 或调试模式显示；
- 文件日志保存完整细节；
- 限制 UI 日志最大行数。
