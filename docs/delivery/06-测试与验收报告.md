## 7. 相机验收状态

基线 `67c1ed0`（旧 MVS SDK）已完成：

- 代码编译；
- SDK 返回值检查；
- 重复采集状态自动测试；
- 回调帧格式与长度校验；
- 回调点云互斥保护；
- 失败清理路径代码审查。

基线之后相机链路已整体重写（Mv3dLp、`Profile/ABC16`、逐帧扫描输出），原结论不再适用。以下内容来自 2026-11 开发期的实机探针（MV-DP2240-01H，SDK 1.3.3.3），仅作为设计依据，不等同于验收：

- `ImageMode = 4` 实际返回 `Profile/ABC16`，不是 float 点云；
- 回调中 `fXScale/fYScale/fZScale` 恒为 0，只能用 `LSLProfileCoordXUnit/ZUnit`；
- 设定 600 Hz 实测约 491 行/s；
- 批次行数 20~50 浮动，帧号不保证逐批 +1。

尚不能仅凭自动测试确认：

- 实际相机能否枚举和连接；
- `LSLStepDistance`、行率和机器人速度是否自洽；
- 采集点云尺度和方向是否正确；
- 手眼标定后基坐标点云是否与机器人位姿一致；
- 长时间连续采集是否稳定；
- 相机在扫描中途断开时的处理。

正式现场验收必须包含物理相机和机械臂测试。

## 8. 标准验收用例

### TC-01 启动

步骤：

1. 启动程序；
2. 检查两个三维视图；
3. 检查状态栏；
4. 检查日志。

预期：

- 程序不崩溃；
- 状态为就绪；
- 日志出现启动记录；
- 未导入数据时匹配按钮不可用。

### TC-02 STEP 导入

步骤：

1. 点击“导入三维模型”；
2. 选择有效 STEP；
3. 旋转、缩放视图。

预期：

- CAD 网格显示；
- 日志给出采样点数；
- 坐标轴显示；
- 无无效面或崩溃。

### TC-03 无效 STEP

步骤：选择损坏或非 STEP 文件。

预期：

- 日志报告失败；
- 旧 CAD 不被错误替换；
- 程序继续可操作。

### TC-04 大点云导入

步骤：

1. 选择大型 PLY；
2. 在加载期间操作窗口；
3. 观察渐进显示。

预期：

- 界面可响应；
- 状态显示后台加载；
- 加载后按百分比显示；
- 最终点数等于清理后的有效点数；
- 显示结束前匹配按钮不可用。

### TC-05 点云清理

输入包含 NaN、Inf 和原点无效点的 PCD/PLY。

预期：

- 无效点被删除；
- 有效点保留；
- 全部无效时给出错误。

### TC-06 模型匹配通过

步骤：

1. 导入匹配 CAD 和点云；
2. 点击模型匹配；
3. 等待完成；
4. 从多个角度检查叠加。

预期：

- UI 不冻结；
- 日志依次显示预处理、粗配准、自动裁剪、精配准；
- 状态为匹配通过；
- 对齐 CAD 叠加在点云上；
- RMSE/P95 和覆盖指标有合理值。

### TC-07 尺度错误

输入比例明显不一致的 CAD 和点云。

预期：

- 日志出现尺寸警告或最终失败；
- 不应通过刚性配准自动引入缩放；
- 焊缝映射不可用。

### TC-08 非同一零件

预期：

- 粗配准无候选，或最终质量不足；
- 不显示错误对齐 CAD；
- 不允许焊缝映射。

### TC-09 对称或歧义

预期：

- `wasAmbiguous` 触发时，日志给出提示和候选诊断；
- 不再自动降为“需要人工确认”，结果取得分最高的候选，仍可能为 `Pass`；
- 操作员必须依据对齐 CAD 叠加效果判断是否为正确姿态，再决定是否映射和执行；
- 若指标低于 `Fail` 门槛，则不显示对齐 CAD，焊缝映射不可用。

### TC-10 创建焊缝

步骤：

1. 点击新建焊缝；
2. Ctrl+单击两个相交面。

预期：

- 两个面分别高亮；
- 生成焊缝；
- 列表出现名称；
- 日志显示长度、点数或管道段数；
- 管道连续可见。

### TC-11 错误选面

场景：

- 两次选择同一面；
- 两面不相交；
- 未导入 CAD。

预期：

- 给出提示；
- 不生成无效焊缝；
- 状态机可取消或重新开始。

### TC-12 焊缝映射

步骤：

1. 创建至少两条焊缝；
2. 完成 `Pass` 匹配；
3. 选择一条；
4. 点击映射。

预期：

- 仅映射当前选中焊缝；
- CAD 和点云视图中同一焊缝高亮；
- 切换列表后两个视图立即同步高亮；
- 映射长度和线段数量不变。

### TC-13 输入替换使结果失效

步骤：

1. 完成匹配并映射焊缝；
2. 导入新点云。

预期：

- 旧匹配结果清空；
- 旧映射 actor 清空；
- 映射按钮禁用；
- 必须重新匹配。

### TC-14 相机重复启动

步骤：采集中重复点击开始拍摄。

预期：

- 按钮通常已禁用；
- 即使进入方法，状态类也拒绝重复启动；
- 累积点云不被并发清空。

### TC-15 支撑平面剔除

输入：带底板的扫描场景。

预期：

- 日志出现“平面候选 N”行，给出点数、高度、下方/上方比例；
- 底板被判定为支撑面并剔除，日志出现“剔除支撑平面：A 点 -> B 点”；
- 工件顶面（下方还有底板）不会被判定为支撑面；
- 若剔除后主体尺寸比过小，日志出现“疑似误删工件表面，已回退”并采用未剔除的结果；
- 找不到支撑面时日志出现“未识别到支撑平面，保留全部点”。

### TC-16 设备连接与状态指示

步骤：

1. 在“通信”菜单依次连接相机、机械臂；
2. 观察状态指示灯；
3. 在机械臂运动时观察指示灯；
4. 拔掉网线或使控制器断电。

预期：

- 灰=未连接，灰闪=连接中，绿=已连接，绿闪=机械臂运动中，红=故障；
- 机械臂断链或 20004 状态流停更超过 1 s，指示灯变红，界面报警条出现错误级报警；
- 界面“解除报警”只清除界面报警条；“通信 → 清除报警”对应机械臂故障复位（`resetFault`），二者不同；
- Debug 构建点击连接机械臂，日志提示“当前构建未启用机械臂 SDK（仅 Release 配置支持）”。

### TC-17 机械臂扫描采集

前提：相机和机械臂在线，工作区无人无障碍，Release 构建。

步骤：

1. “执行 → 开始扫描采集”（Ctrl+Shift+S）；
2. 在确认框核对当前位姿与扫描位姿后确认；
3. 观察抬升、调平、扫描、退回；
4. 扫描中途点击“取消扫描”（另做一次）。

预期：

- 先竖直抬升（若低于 150 mm），再调平到 Rx 180 / Ry 0 / Rz 90；
- 沿工具 X 轴直线扫描约 200 mm；
- 扫描后自动退回起点；
- 日志给出实收批数、行数、实收行率、帧号跳变和等效步距复核；
- 输出基坐标点云，点云平均 Z 低于扫描起点 TCP Z；
- 取消扫描时机械臂立即停止，相机停流，激光熄灭；
- 相机或机械臂在扫描中断开，扫描判失败并停机。

### TC-18 手眼标定核对

依据 `docs/calibration/README.md` 第 3.2 节：

1. 扫一幅基坐标点云，点云平均 Z 必须低于扫描起点 TCP Z；
2. 设好一条已知焊缝的起点并映射，用“移动至焊缝起点上方（30 mm）”让 TCP 到位，目测尖端是否落在起点正上方 30 mm；
3. 同一工件正反两个方向各扫一次，比较特征点基坐标，据此标定 `timeOffsetUs`；
4. 编辑 `calibration.json` 后，“通信 → 重新加载手眼标定”生效，且无效文件给出明确提示。

预期：偏差大于 1~2 mm 时先复核 `sensorAxis` 与外参。

### TC-19 焊缝起点与方向

步骤：

1. 选中焊缝，点击“设定起点”，Ctrl+单击一端；
2. 点击“反转方向”；
3. 对已映射的焊缝重复上述操作。

预期：

- CAD 与点云视图均出现青色起点球标和走向箭头；
- 列表行出现 ▶；
- 已映射焊缝改动方向后，映射被重建，起点与方向保持一致；
- 容差外的拾取被拒绝，焊缝数据不变。

### TC-20 焊缝轨迹执行

前提：基坐标点云、匹配 `Pass`、焊缝已设起点并映射、机械臂在线，现场人员能随时触达急停。

步骤：

1. “执行 → 移动至焊缝起点上方（30 mm）”；
2. “执行 → 焊缝空走”；
3. “执行 → 沿焊缝执行”；
4. 执行中按 `Esc` 或点击“停止轨迹运动”。

预期：

- 步骤 1：尖端位于起点正上方 30 mm，偏差在可接受范围；
- 步骤 2：整条轨迹抬高 20 mm，尖端距焊缝约 30 mm，执行后返回拍摄起点；
- 步骤 3：沿焊缝行走，终点上方退出，再按“抬升 → 平移转姿态 → 下降”返回拍摄起点，不斜穿工件；
- 步骤 4：立即停机，且不自动返回；
- 点云为传感器坐标、或匹配非 `Pass`、或焊缝未映射时，相关菜单项禁用；
- 焊缝最高点比当前 TCP 高出 100 mm 以上时，被拒绝并给出日志；
- 末端偏离竖直超过 30° 时，被拒绝。

### TC-21 构建后部署

步骤：Release 构建完成后，直接运行输出目录中的 `dianyun.exe`。

预期：

- 程序启动，不报 `no Qt platform plugin could be initialized`；
- 输出目录中 Qt 核心库与 `platforms/qwindows.dll` 版本一致；
- `fairino.dll` 位于 exe 同目录。

## 10. 验收结论

2026-07 基线 `67c1ed0` 的核心软件链路已通过编译、自动测试和人工功能验证：

```text
STEP/点云导入
-> 全自动刚体模型匹配
-> 质量判定
-> CAD 焊缝创建
-> 选中焊缝刚性映射
-> 两视图同步高亮
```

当前版本 `c006de3` 在此基础上新增了扫描采集、基坐标点云、机械臂联动和焊缝轨迹执行。这些新增链路：

- 自动测试用例已加入（扫描拼接、位姿换算、轨迹规划、焊缝起点），但本次未重新运行；
- 现场有部分标定核对记录（见 7.1），没有完整的端到端验收记录；
- 匹配判定已简化为 `Pass / Fail`，预处理平面剔除算法已替换，基线的人工验证不能直接沿用。

因此，**当前版本尚不能宣称已完成验收**。剩余验收重点：

- 重新编译并运行自动测试；
- 按 TC-15 ~ TC-21 完成支撑平面、设备、扫描、标定、起点和轨迹验收；
- 补第三个已知点复核手眼标定的偏航；
- 新计算机依赖复现，尤其是 Mv3dLp 运行时 DLL；
- 更多工件和更多拍摄角度；
- 长时间稳定性；
- 正式交付数据和远程 Git 同步。
