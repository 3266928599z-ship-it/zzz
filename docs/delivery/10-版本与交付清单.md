## 13. 交付风险

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 本地领先远程 1 提交（本机缓存，可能已过期） | 远程可能缺少最新代码 | 联网 `git fetch` 复核，明确授权后推送 |
| 文档更新在代码提交之后 | 文档尚需单独提交 | 创建文档提交 |
| 依赖绝对路径 | 新机器编译失败 | 路径配置或依赖统一 |
| Mv3dLp 运行时 DLL 未入库、无部署目标 | 新机器启动或连接相机失败 | 确认来源，补充部署说明或构建后目标 |
| 法奥 SDK 与控制器固件必须一致 | 版本错配时 `MoveL` 解析失败 | 控制器 web 版本非 v3.9.3.x 时需更换对应 SDK 分支 |
| Debug 配置不含机械臂 SDK | Debug 下无法连接机械臂 | 联调使用 Release |
| 手眼标定存在残差（旋转项约 3° 偏航未确认） | 焊缝起点存在 mm 级偏差 | 补第三个已知点复标；首次执行前先空走核对 |
| 机械臂运动未做逆解预检与碰撞检测 | 不可达点在对应段才报错停机 | 现场保持急停可达，先空走 |
| 相机与机械臂未完整自动测试 | 现场不确定 | 物理设备验收 |
| 无结果导出 | 交付结果不可持久化 | 后续增加 JSON/CSV |
