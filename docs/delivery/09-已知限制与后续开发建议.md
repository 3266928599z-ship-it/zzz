# 已知限制与后续开发建议

## 1. 文档目的

本文档明确当前版本的能力边界，避免把已实现的刚体模型匹配和焊缝显示误解为完整生产级焊接系统。

## 2. 当前已知限制

### 2.1 依赖路径不可移植

项目文件包含：

- `E:\Qt`；
- `E:\vcpkg-master`；
- `E:\PCL 1.15.1`；
- `E:\MVS`；
- 残留 `Z:\vcpkg-master`。

影响：

- 新计算机不能直接编译；
- 依赖版本容易混用；
- CI 难以建立。

优先级：高。

建议：

- 统一 vcpkg manifest；
- MVS 作为可选 SDK；
- 使用环境变量或 MSBuild 属性；
- 删除机器特定 `.vcxproj.user` 交付依赖。

### 2.2 测试覆盖有限

当前自动测试集中于：

- 请求版本；
- 相机状态；
- 焊缝刚性矩阵和坐标。

尚未自动覆盖：

- STEP 读取；
- PLY/PCD 读取；
- 预处理；
- 粗配准；
- ICP；
- 质量判定；
- VisualizationManager；
- UI 操作；
- 相机真实帧解析。

优先级：高。

### 2.3 模型匹配测试数据在仓库外

当前测试 STEP/PLY 位于 `E:\document`。

影响：

- 接手人员无法从仓库复现；
- 文件可能被覆盖；
- 没有哈希和数据版本。

建议：

- 建立 `test-data` 独立包；
- 保存 README、来源、单位和哈希；
- 大文件使用 Git LFS、发布附件或内部对象存储；
- 不把敏感现场数据放入公开仓库。

### 2.4 只支持刚性且同尺度

算法只允许旋转和平移。

不支持：

- 缩放；
- 镜像；
- 剪切；
- 弹性形变；
- 焊接变形；
- 制造偏差补偿。

这是一项设计约束，不是简单增加 ICP 迭代即可解决。

### 2.5 残缺点云依赖可辨识结构

若扫描只保留：

- 单一平面；
- 圆柱对称面；
- 重复槽；
- 无孔无边的局部区域；

则几何上可能不存在唯一姿态。

程序会尽量通过特征、空间覆盖和歧义判定避免误判，但不能创造不存在的信息。

### 2.6 自动工件聚类只选择一个主体

当前预处理只保留评分最高的聚类。

风险：

- 工件因遮挡分裂为多个连通区域；
- 主体被误选为夹具；
- 多个合理区域未共同参与匹配。

后续可保留前 K 个合理聚类，分别进入粗配准并统一评分。

### 2.7 PPF 计算与稳定性

PPF 点对特征规模大，因此限制 CAD 500 点、扫描 1400 点。

风险：

- 过度稀疏时小特征丢失；
- PPF 实现可能受法向方向影响；
- 异常仅记录并回退，不保证总能产生候选。

### 2.8 匹配任务不可取消

界面“取消操作”只取消焊缝选面，不取消模型匹配。

`QThread::quit()` 不能中断正在执行的 CPU 函数。

建议：

- Worker 使用原子取消标志；
- 每个长循环检查；
- PCL 黑盒调用前后检查；
- UI 增加“取消匹配”按钮；
- 明确取消后的结果作废。

### 2.9 相机参数和像素格式硬编码

限制：

- 使用第一个设备；
- 固定像素格式 `0x022000BB`；
- 固定默认 `xRes/yRes/zScale`；
- `runSpeed` 当前未使用；
- 没有设备选择或参数界面；
- 没有配置持久化。

优先级：高，若进入现场使用。

### 2.10 相机坐标未标定到工位或机器人

当前点云是相机局部坐标。

缺失：

- 手眼标定；
- 相机到工装外参；
- 工件到机器人基坐标；
- 时间同步；
- 运动轴编码器同步。

焊缝映射到扫描点云不等于已经得到机器人可执行坐标。

### 2.11 焊缝只做刚性映射

当前不会：

- 吸附到实际表面；
- 补偿制造误差；
- 穿越扫描缺失；
- 估计焊缝法向；
- 生成焊枪姿态；
- 做碰撞检查。

因此结果适合显示和后续算法输入，不应直接下发机器人。

### 2.12 没有结果导出

当前不能保存：

- `T_final`；
- 质量指标；
- 对齐点云；
- 焊缝点；
- 日志；
- 项目会话。

关闭程序后结果丢失。

### 2.13 日志未分级、未持久化

日志仅显示在 UI。

风险：

- 崩溃后日志丢失；
- 候选报告过长；
- 无统一问题追踪 ID；
- 难以统计性能。

### 2.14 可视化可能产生多个点云 actor

完整点云每 100000 点创建一个 actor。

大点云会产生较多 actor，可能增加：

- VTK 管理开销；
- GPU 内存；
- 交互延迟。

目前满足“显示全部点”的需求，但可进一步优化为单 actor 增量数据或 LOD。

### 2.15 参数全部编译期固定

没有：

- 配置文件；
- 设置界面；
- 参数合法性报告；
- 参数版本。

算法调优需要重新编译。

### 2.16 Debug 和 Release 依赖配置不完全对称

Release 显式配置了更多 PCL 库路径、宏和 AVX。Debug 依赖较少，可能比 Release 更容易出现链接问题。

建议把共用配置移入 `.props`。

### 2.17 可维护性

`ModelMatchWorker.cpp` 仍较大，包含多个阶段。

目前可读性尚可，但继续增加算法将导致：

- 编译慢；
- 难以单测；
- 阶段状态耦合；
- 调参影响不清晰。

## 3. 后续开发路线

### 阶段 1：交付工程化

优先级最高。

1. 同步本地提交到受控远程仓库；
2. 复核并持续维护现有 Visual Studio `.gitignore`；
3. 统一依赖路径；
4. 建立 vcpkg manifest 或依赖安装脚本；
5. 增加 `BUILD_CAMERA` 开关；
6. 将配置外部化；
7. 建立测试数据清单；
8. 添加 CI Release 编译和测试。

验收：

- 新计算机按文档一次配置成功；
- 无绝对路径修改也能构建，或只需修改一个配置文件；
- CI 自动输出测试结果。

### 阶段 2：算法可测试化

建议拆分：

```text
PointCloudPreprocessor
FeatureExtractor
CoarseRegistrationService
GuidedCropService
FineRegistrationService
MatchQualityEvaluator
```

每个阶段：

- 输入输出明确；
- 无 UI；
- 可保存中间结果；
- 有小型点云测试；
- 有失败用例。

### 阶段 3：结果持久化

新增：

- 配准结果 JSON；
- 4×4 矩阵；
- 所有质量指标；
- 输入文件哈希；
- 参数快照；
- 时间戳和版本；
- 焊缝 CSV/PLY/JSON；
- 可选对齐点云。

推荐结果结构：

```json
{
  "schema_version": 1,
  "software_commit": "67c1ed0",
  "cad_file": "...",
  "scan_file": "...",
  "units": "mm",
  "transform_direction": "cad_to_scan",
  "T_final": [],
  "metrics": {},
  "verdict": "Pass",
  "parameters": {}
}
```

### 阶段 4：相机产品化

1. 设备列表与选择；
2. 参数读取和写入；
3. 像素格式枚举；
4. 帧统计、丢帧和超时；
5. 标定文件；
6. 运动速度/触发频率与 Y 坐标关系；
7. 相机重连；
8. 录制原始帧用于离线回放测试；
9. 工位外参。

### 阶段 5：焊缝实际表面投影

建议保留两套数据：

- `rigidMappedSeam`：当前刚性基准；
- `surfaceAdjustedSeam`：扫描表面调整结果。

推荐算法约束：

1. 只在刚性焊缝附近半径内搜索；
2. 使用局部曲面法向；
3. 拒绝跳到相邻错误面；
4. 保持点序；
5. 对位移做平滑；
6. 对缺失区间保持 CAD 预测或标记无观测；
7. 输出每点置信度；
8. 不改变端点和长度时应显式说明；
9. 能回退到刚性结果。

### 阶段 6：焊接轨迹与机器人

在焊缝表面调整稳定后，再增加：

- 切向；
- 两侧表面法向；
- 焊枪姿态；
- 工作角和行走角；
- 速度；
- 起弧/收弧；
- 工具中心点；
- 机器人逆解；
- 可达性；
- 碰撞检查；
- 轨迹导出；
- 工位坐标转换。

## 4. 建议新增测试

### 算法单元测试

- 体素尺寸；
- 平面删除保底；
- 聚类选择；
- 空间覆盖；
- 候选去重；
- 刚性矩阵验证；
- 判定阈值边界。

### 合成配准测试

1. 从 CAD 点云生成局部扫描；
2. 应用已知刚性变换；
3. 添加噪声、离群点和遮挡；
4. 运行配准；
5. 比较估计矩阵与真值。

指标：

- 旋转误差；
- 平移误差；
- 通过率；
- 误通过率；
- 运行时间。

### 回归数据集

至少覆盖：

- 正常角度；
- 极端角度；
- 轻度/中度/重度缺失；
- 底板；
- 夹具；
- 定位环；
- 对称多解；
- 尺度错误；
- 非同一零件。

## 5. 优先级建议

| 优先级 | 项目 |
| --- | --- |
| P0 | 远程代码同步、依赖可复现、测试数据受控 |
| P0 | 物理相机标定和现场验收 |
| P1 | 配准结果和参数持久化 |
| P1 | 合成配准自动测试 |
| P1 | 匹配取消和超时 |
| P1 | 相机设备/格式/参数配置 |
| P2 | 算法模块拆分 |
| P2 | 日志等级和文件日志 |
| P2 | 焊缝受约束表面投影 |
| P3 | 机器人轨迹、姿态和碰撞 |

## 6. 禁止直接用于生产的情况

在以下条件未完成前，不应直接驱动焊接机器人：

- 未完成相机外参标定；
- 未验证 CAD/扫描单位；
- 匹配结果不是 `Pass`；
- 未建立矩阵和焊缝结果导出校验；
- 未进行焊缝表面调整或误差评估；
- 未生成焊枪姿态；
- 未进行可达性与碰撞检查；
- 未建立急停、权限和人工确认流程。
