# 项目功能说明

## 1. 项目概述

`dianyun` 是一个运行于 Windows 的三维工件处理桌面软件，基于 Qt、PCL、OpenCascade、VTK 和海康 MVS SDK 开发。

当前版本的核心目标是：

1. 读取完整的 STEP/STP CAD 模型；
2. 读取或采集可能不完整、带遮挡和夹具干扰的扫描点云；
3. 自动完成 CAD 与扫描点云之间的刚性模型匹配；
4. 输出可解释的匹配质量指标；
5. 在 CAD 上创建焊缝；
6. 将已选焊缝按匹配结果刚性映射到扫描点云坐标系。

本项目不是通用 CAD 编辑器，也不是完整焊接机器人离线编程系统。当前交付重点是三维数据导入、自动刚体配准、可视化复核和焊缝刚性映射。

## 2. 典型应用场景

典型工作场景如下：

- 已有工件设计模型，格式为 STEP/STP；
- 通过三维相机获得工件扫描点云，格式为 PLY/PCD，或直接从海康相机采集；
- 扫描只能看到工件的一部分，可能包含底板、夹具、定位环和离群点；
- 需要计算 CAD 坐标系到扫描坐标系的刚性变换；
- 在 CAD 上定义的焊缝需要随刚性变换显示到扫描点云中，供人工检查或后续轨迹处理使用。

## 3. 界面组成

主界面分为四个主要区域：

| 区域 | 作用 |
| --- | --- |
| 顶部操作栏 | 导入三维模型、导入点云、模型匹配、开始拍摄 |
| 左侧“三维模型”视图 | 显示 CAD 网格、选面高亮、CAD 焊缝 |
| 中间“点云模型”视图 | 显示完整点云、处理后工件点云、对齐 CAD、映射焊缝 |
| 右侧区域 | 匹配状态、焊缝列表、焊缝操作、运行日志 |

三维显示实际由两个 PCL Visualizer 实例组成：

- `m_cadViewer`：CAD 视图；
- `m_scanViewer`：扫描点云与匹配结果视图。

## 4. 功能清单

### 4.1 STEP/STP 模型导入

入口：顶部“导入三维模型”。

实现内容：

- 使用 OpenCascade `STEPControl_Reader` 读取文件；
- 合并根实体并检查是否存在有效形状；
- 计算 CAD 包围盒对角线；
- 对所有面执行三角化；
- 建立三角单元到 CAD 面编号的映射；
- 按三角形面积在 CAD 表面生成配准采样点；
- 在左侧视图显示灰色 CAD 网格；
- 导入新 CAD 时清空旧焊缝、旧匹配结果和旧映射结果。

支持格式：

- `.step`
- `.stp`

失败条件：

- STEP 文件读取失败；
- 文件中没有有效实体；
- 模型尺寸无效；
- 三角化或表面采样失败。

### 4.2 PLY/PCD 点云导入

入口：顶部“导入点云模型”。

实现内容：

- 使用后台任务读取文件，主界面不会在文件读取期间卡死；
- 支持 PLY 和 PCD；
- 删除 NaN、Inf 和接近原点的无效点；
- 计算点云包围盒对角线；
- 保留全部有效点；
- 使用每批 100000 点的渐进方式显示；
- 点云全部显示完毕后才允许开始模型匹配；
- 导入新点云时清除旧匹配结果和旧焊缝映射。

支持格式：

- `.ply`
- `.pcd`

注意：点云文件越大，读取、内存占用和完整渲染时间越长。程序并未为了显示而永久删除点。

### 4.3 海康三维相机采集

入口：顶部“开始拍摄”。

实现内容：

- 枚举 GigE 和 USB 相机；
- 创建并打开第一个可用设备；
- 注册图像回调；
- 设置连续触发模式；
- 接收坐标数据帧；
- 按 `xRes`、`yRes` 和 `zScale` 重建点；
- 达到目标行程后输出完整点云；
- 防止重复启动采集；
- 检查 SDK 返回值、像素格式和帧长度；
- 使用互斥锁保护回调线程中的累积点云。

默认相机参数见 [07-配置参数说明](07-配置参数说明.md)。

相机功能依赖实际硬件、MVS 驱动、网络或 USB 连接以及正确的设备像素格式。自动测试不覆盖物理相机。

### 4.4 完整点云渐进显示

目的：既显示全部点，又避免一次性创建数百万点的渲染对象导致界面长时间无响应。

行为：

- 点云导入完成后，仅保存共享指针，不复制全部点；
- 每次 30 ms 界面定时器触发一次更新；
- 每次最多追加 100000 点；
- 使用点的 `z` 字段着色；
- 第一批点显示时重置相机；
- 状态栏显示当前渲染百分比；
- 渲染完成前禁用模型匹配。

### 4.5 全自动模型匹配

入口：顶部“模型匹配”。

前置条件：

- CAD 已成功导入；
- 点云已成功导入或采集；
- 完整点云的渐进显示已经结束；
- 当前没有点云读取、相机采集或另一项匹配任务。

总体流程：

1. CAD 尺寸驱动的体素降采样；
2. 扫描最大平面剔除；
3. 统计离群点滤波；
4. 欧式聚类选择工件主体；
5. 法向和曲率估计；
6. 高显著性关键点和 FPFH 特征提取；
7. FPFH、PPF 和 PCA 多来源粗配准候选；
8. 候选质量评分和去重；
9. CAD 引导的三层自动裁剪；
10. 多候选鲁棒点到点 ICP；
11. 最佳候选的鲁棒点到面 ICP；
12. 质量下降时自动回退；
13. 计算质量指标；
14. 输出通过、人工确认或失败。

模型匹配运行在独立 `QThread` 中，避免阻塞主界面。

### 4.6 匹配结果显示

匹配成功且结果不是 `Fail` 时：

- 将 CAD 表面采样点按 `T_final` 变换到扫描坐标系；
- 使用灰色显示；
- 设置透明度为 0.5；
- 叠加在点云视图中供人工复核。

`Fail` 结果不会显示对齐 CAD，以避免将低质量结果误认为有效结果。

### 4.7 匹配质量输出

日志和 `MatchResult` 中包含：

- 扫描覆盖率；
- CAD 反向支持率；
- 关键特征覆盖率；
- 空间结构覆盖率；
- 法向一致性；
- RMSE；
- P95 残差；
- 点到面 ICP 迭代次数；
- 点到面 ICP 是否收敛；
- 是否存在多解歧义；
- 粗配准候选诊断文本。

结果分为：

| 状态 | 含义 | 后续行为 |
| --- | --- | --- |
| `Pass` | 指标达到可信门槛 | 可显示对齐 CAD，可进行焊缝映射 |
| `NeedsReview` | 基本对齐但收敛、覆盖或歧义仍需确认 | 显示对齐 CAD，不允许焊缝映射 |
| `Fail` | 指标低于最低门槛或计算失败 | 不显示对齐 CAD，不允许映射 |

### 4.8 CAD 焊缝创建

入口：右侧“新建焊缝”。

操作：

1. 导入 CAD；
2. 点击“新建焊缝”；
3. 按住 `Ctrl`，在左侧 CAD 视图单击第一个面；
4. 继续按住 `Ctrl`，单击第二个不同面；
5. 程序计算两个面的交线并生成焊缝。

实现内容：

- 使用 VTK Cell Picker 取得三角单元；
- 通过 `cellToFaceMap` 找回 OpenCascade 面；
- 使用 `BRepAlgoAPI_Section` 计算面交线；
- 遍历交线边；
- 按曲线参数采样；
- 保存采样点、连续线段、总长度、编号和名称；
- 使用三维管道而不是单像素线显示。

### 4.9 焊缝管理

支持：

- 在列表显示焊缝；
- 选中焊缝；
- 同时高亮 CAD 视图和点云视图中的同一条焊缝；
- 删除选中焊缝；
- 取消正在进行的选面操作；
- CAD 更换时清空全部焊缝。

默认颜色：

- 未选 CAD 焊缝：绿色；
- 选中 CAD 焊缝：洋红色；
- 未选映射焊缝：橙黄色；
- 选中映射焊缝：洋红色。

### 4.10 焊缝刚性映射

入口：右侧“焊缝映射”。

前置条件：

- 焊缝列表中已选中一条焊缝；
- 最新模型匹配执行成功；
- 最新结果必须为 `Pass`；
- 自匹配完成后 CAD 和扫描点云没有被替换。

行为：

- 验证 `T_final` 为有限、齐次、正交且行列式为正的刚性矩阵；
- 对焊缝采样点和每个线段端点执行相同刚性变换；
- 保持焊缝名称、编号、长度、采样点数量和线段数量；
- 在点云视图显示映射后的三维管道；
- 不做最近点吸附；
- 不修改焊缝几何来适应扫描缺失。

## 5. 输入与输出

### 5.1 输入

| 输入 | 格式 | 必须条件 |
| --- | --- | --- |
| CAD 模型 | STEP/STP | 有效实体、尺寸有效、可三角化 |
| 扫描点云 | PLY/PCD | 至少包含 100 个有效点 |
| 相机帧 | 海康坐标像素格式 | 驱动、SDK、设备和标定参数正确 |
| 选面操作 | 两个不同 CAD 面 | 两个面存在有效交线 |

### 5.2 内部输出

| 输出 | 类型 | 说明 |
| --- | --- | --- |
| `CadModelData` | CAD 数据 | 形状、面、网格、采样点和尺寸 |
| `MatchResult` | 配准结果 | `T_final`、指标、判定和诊断 |
| `WeldSeamData` | 焊缝数据 | 采样点、线段、长度和标识 |
| 对齐 CAD | 可视化结果 | 半透明叠加，不写入外部文件 |
| 映射焊缝 | 可视化结果 | 刚性变换后的焊缝，不写入外部文件 |

当前版本没有提供以下持久化输出：

- 配准矩阵导出文件；
- 对齐点云或 CAD 导出文件；
- 焊缝坐标导出文件；
- 工程项目文件；
- 用户配置文件。

## 6. 功能边界

当前不包含：

- 非刚性配准；
- 自动尺度估计或单位转换；
- 镜像模型匹配；
- 多帧相机位姿融合；
- 相机与机器人外参标定；
- 焊缝向扫描最近表面的二次吸附；
- 焊枪姿态、法向、进给速度或机器人轨迹生成；
- 焊缝质量检测；
- 结果文件保存与恢复；
- 撤销/重做；
- 多 CAD、多点云批处理。

## 7. 正确使用原则

1. CAD 和点云必须表示同一零件。
2. CAD 和点云必须使用同一长度单位。
3. 点云可以残缺，但必须保留足够的非对称结构或高辨识度特征。
4. 大面积平面、圆柱对称和重复结构容易产生多解。
5. `NeedsReview` 只能用于人工观察，不能直接作为焊缝映射依据。
6. 映射焊缝的精度不会高于模型匹配精度。
7. 任何 CAD 或点云替换都会使旧匹配结果失效。
