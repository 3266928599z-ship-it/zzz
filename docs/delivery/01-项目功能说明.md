# 项目功能说明

## 1. 项目概述

`dianyun` 是一个运行于 Windows 的三维工件处理桌面软件，基于 Qt、PCL、OpenCascade、VTK、海康 3D 线激光相机 SDK（Mv3dLp）和法奥（FAIRINO）机械臂 C++ SDK 开发。

当前版本的核心目标是：

1. 读取完整的 STEP/STP CAD 模型；
2. 读取或采集可能不完整、带遮挡和夹具干扰的扫描点云；其中相机采集支持「相机持续出流 + 机械臂直线行走」的整幅拼接扫描，并可直接输出机器人基坐标点云；
3. 自动完成 CAD 与扫描点云之间的刚性模型匹配；
4. 输出可解释的匹配质量指标；
5. 在 CAD 上创建焊缝，并设定起焊点与焊接方向；
6. 将已选焊缝按匹配结果刚性映射到扫描点云坐标系；
7. 基于基坐标下的映射焊缝生成 TCP 轨迹，驱动机械臂移动至焊缝起点上方、空走或沿焊缝执行，并在结束后返回拍摄起点。

本项目不是通用 CAD 编辑器，也不是完整焊接机器人离线编程系统。轨迹只做几何规划（接近、下降、沿焊缝、退出、返回），不包含焊接工艺参数、逆解预检和焊接质量闭环。

## 2. 典型应用场景

典型工作场景如下：

- 已有工件设计模型，格式为 STEP/STP；
- 通过三维相机获得工件扫描点云，格式为 PLY/PCD，或直接从海康相机采集；
- 扫描只能看到工件的一部分，可能包含底板、夹具、定位环和离群点；
- 需要计算 CAD 坐标系到扫描坐标系的刚性变换；
- 在 CAD 上定义的焊缝需要随刚性变换显示到扫描点云中，供人工检查；
- 扫描点云来自机械臂携带的线激光相机，焊缝映射结果位于机器人基坐标系，可直接生成轨迹交由机械臂执行。

## 3. 界面组成

主界面采用深色工业风，由菜单栏和四个主要区域组成。

菜单栏：

| 菜单 | 内容 |

| 执行 | 开始扫描采集（Ctrl+Shift+S）、取消扫描、移动至焊缝起点上方（30 mm）、焊缝空走、沿焊缝执行、停止轨迹运动（Esc） |
| 帮助 | 操作说明、关于 |

主界面区域：

| 区域 | 作用 |
| --- | --- |
| 顶部操作栏 | 导入三维模型、导入点云、模型匹配、开始拍摄、机械臂焊接、视图复位，以及设备状态指示灯和报警区 |

- `m_scanViewer`：扫描点云与匹配结果视图。

## 4. 功能清单

### 4.1 STEP/STP 模型导入

入口：顶部“导入三维模型”。

实现内容：

- 使用 OpenCascade `STEPControl_Reader` 读取文件；
- 合并根实体并检查是否存在有效形状；
- 计算 CAD 包围盒对角线；
- 对所有面执行三角化；
- 建立三角单元到 CAD 面编号的映射；
- 按三角形面积在 CAD 表面生成配准采样点；
- 在左侧视图显示灰色 CAD 网格；
- 导入新 CAD 时清空旧焊缝、旧匹配结果和旧映射结果。

支持格式：

- `.step`
- `.stp`

失败条件：

- STEP 文件读取失败；
- 文件中没有有效实体；
- 模型尺寸无效；
- 三角化或表面采样失败。

### 4.2 PLY/PCD 点云导入

入口：顶部“导入点云模型”。

实现内容：

- 使用后台任务读取文件，主界面不会在文件读取期间卡死；
- 支持 PLY 和 PCD；
- 删除 NaN、Inf 和接近原点的无效点；
- 计算点云包围盒对角线；
- 保留全部有效点；
- 使用每批 100000 点的渐进方式显示；
- 点云全部显示完毕后才允许开始模型匹配；
- 导入新点云时清除旧匹配结果和旧焊缝映射。

支持格式：

- `.ply`
- `.pcd`

注意：点云文件越大，读取、内存占用和完整渲染时间越长。程序并未为了显示而永久删除点。

### 4.3 海康三维相机采集

入口：顶部“开始拍摄”（单帧）；菜单“执行 → 开始扫描采集”（机械臂行走拼接）；菜单“通信”中的相机连接/断开。

相机为海康线激光轮廓传感器（实测型号 MV-DP2240-01H，Mv3dLp SDK 1.3.3.3），由 `HikCameraWorker` 在独立线程中管理，生命周期分四层：SDK 初始化、设备连接、数据流、采集窗口。

实现内容：

- 连接/断开与采集启停分离，状态为 `Disconnected / Connecting / Connected / Capturing / Fault`，由状态指示灯显示；
- `ImageMode = 4` 输出 `Profile/ABC16`（3×int16）：A 为 X 编码值，B 恒为 0，C 为 Z 编码值，空点三个分量同为 -32768；按 `LSLProfileCoordXUnit/ZUnit`（µm/count）换算为毫米；
- 设备把多行轮廓打成一批，每批行数不固定（实测 20~50 行），批次内没有行坐标，Y 只能由上位机补齐；
- 单帧模式：累积 `frameCount` 批后输出单张点云；
- 扫描模式：逐帧输出 `ScanFrame`，由 `ScanSession` 按行序号拼接；
- 采集看门狗按帧数与行率推算超时；
- 防止重复启动采集，使用状态机和互斥锁保护回调线程中的数据。

扫描几何必须自洽：`速度(mm/s) = 步距(µm) × 行率(Hz) / 1000`。本机标定值 96 µm × 491 行/s ≈ 47 mm/s。默认参数见 [07-配置参数说明](07-配置参数说明.md)。

相机功能依赖实际硬件、Mv3dLp 运行库、网络连接。自动测试覆盖扫描拼接、位姿换算和轨迹规划，不覆盖物理相机和机械臂。

### 4.3.1 机械臂监控与扫描采集

入口：菜单“通信”中的机械臂条目；菜单“执行 → 开始扫描采集”。

`RobotWorker` 基于法奥 `fairino-cpp-sdk` 3.9.3 分支（SDK V2.3.3.0，对应控制器 web 版本 v3.9.3.1），在独立线程中：

- 以 100 ms 周期轮询状态，读取机器人状态、程序状态、急停、故障码和 TCP 位姿；
- 连续失败 5 次，或 20004 状态流停更超过 1 秒，判定链路故障；
- 通过非阻塞 `MoveL / MoveCart` 加 `motion_done` 轮询下发运动指令，`stopMotion()` 可及时生效。

`ScanController` 编排一次扫描：

```text
Idle → Positioning(可选) → Starting(起流) → Scanning(MoveL) → Stopping(收尾) → Done / Failed
```

- 定位可拆为「竖直抬升」和「调姿态」两段，避免低位斜插穿过工件；
- 扫描姿态固定为 Rx 180 / Ry 0 / Rz 90，基坐标 Z 抬到 150 mm，沿工具 X 轴（基坐标 +Y）直线扫描 200 mm；
- 相机先于运动起流、到位后再等待约 300 ms 才停流，保证行程两端有数据；
- 首帧不计入拼接；机器人位移超过 0.5 mm 后才开始记录；
- 扫描结束默认直线退回起点；
- 任何失败路径都同时 `StopMotion()` 与停止采集，避免激光无人看管常亮。

点云坐标系：

- 已加载有效手眼标定（`calibration.json`）且轨迹样本充足时，按行时间戳在 TCP 轨迹上插值（平移线性、姿态 slerp），输出机器人基坐标点云（`CloudFrame::RobotBase`）；
- 标定无效、轨迹不足、文件导入和单帧拍摄时，点云属于传感器坐标（`CloudFrame::Sensor`）。

只有 `RobotBase` 点云及其匹配、焊缝映射结果才能下发给机械臂。

当前构建中，只有 Release 配置启用机械臂 SDK（`DIANYUN_ROBOT_SDK`）；Debug 配置下 `RobotWorker` 为空实现，点击连接会提示当前构建未启用机械臂 SDK。

### 4.4 完整点云渐进显示

目的：既显示全部点，又避免一次性创建数百万点的渲染对象导致界面长时间无响应。

行为：

- 点云导入完成后，仅保存共享指针，不复制全部点；
- 每次 30 ms 界面定时器触发一次更新；
- 每次最多追加 100000 点；
- 使用点的 `z` 字段着色；
- 第一批点显示时重置相机；
- 状态栏显示当前渲染百分比；
- 渲染完成前禁用模型匹配。

### 4.5 全自动模型匹配

入口：顶部“模型匹配”。

前置条件：

- CAD 已成功导入；
- 点云已成功导入或采集；
- 完整点云的渐进显示已经结束；
- 当前没有点云读取、相机采集或另一项匹配任务。

总体流程：

1. CAD 尺寸驱动的体素降采样；
2. 统计离群点滤波；
3. 支撑平面剔除：沿 `MatchConfig::scanUpAxis`（默认 +Z）在近水平候选平面中，选取「几乎无点在其下方、且上方有物体」的最低平面；找不到合格平面则不剔除；
4. 欧式聚类选择工件主体；若剔除平面后主体明显小于 CAD（尺寸比 < 0.45）而未剔除时尺寸合理，则回退到未剔除平面的点云；
5. 法向和曲率估计；
6. 高显著性关键点和 FPFH 特征提取；
7. FPFH、PPF 和 PCA 多来源粗配准候选；
8. 候选质量评分和去重；
9. CAD 引导的三层自动裁剪；
10. 多候选鲁棒点到点 ICP；
11. 最佳候选的鲁棒点到面 ICP；
12. 质量下降时自动回退；
13. 计算质量指标；
14. 输出通过或失败。

模型匹配运行在独立 `QThread` 中，避免阻塞主界面。

### 4.6 匹配结果显示

匹配成功且结果不是 `Fail` 时：

- 将 CAD 表面采样点按 `T_final` 变换到扫描坐标系；
- 使用灰色显示；
- 设置透明度为 0.5；
- 叠加在点云视图中供人工复核。

`Fail` 结果不会显示对齐 CAD，以避免将低质量结果误认为有效结果。

### 4.7 匹配质量输出

日志和 `MatchResult` 中包含：

- 扫描覆盖率；
- CAD 反向支持率；
- 关键特征覆盖率；
- 空间结构覆盖率；
- 法向一致性；
- RMSE；
- P95 残差；
- 点到面 ICP 迭代次数；
- 点到面 ICP 是否收敛；
- 是否存在多解歧义；
- 粗配准候选诊断文本。

结果分为两种：

| 状态 | 含义 | 后续行为 |
| --- | --- | --- |
| `Pass` | 达到最低质量门槛 | 显示对齐 CAD，可进行焊缝映射 |
| `Fail` | RMSE 或 P95 残差超过门槛，或计算失败 | 不显示对齐 CAD，不允许映射 |

多解歧义（`wasAmbiguous`）和点到面 ICP 未收敛不再阻断结果：程序取得分最高的候选作为结果，并只在日志中提示。涉及对称或多解的工件，应由操作员依据对齐 CAD 的叠加效果和日志自行复核。

### 4.8 CAD 焊缝创建

入口：右侧“新建焊缝”。

操作：

1. 导入 CAD；
2. 点击“新建焊缝”；
3. 按住 `Ctrl`，在左侧 CAD 视图单击第一个面；
4. 继续按住 `Ctrl`，单击第二个不同面；
5. 程序计算两个面的交线并生成焊缝。

实现内容：

- 使用 VTK Cell Picker 取得三角单元；
- 通过 `cellToFaceMap` 找回 OpenCascade 面；
- 使用 `BRepAlgoAPI_Section` 计算面交线；
- 遍历交线边；
- 按曲线参数采样；
- 保存采样点、连续线段、总长度、编号和名称；
- 使用三维管道而不是单像素线显示。

### 4.9 焊缝管理

支持：

- 在列表显示焊缝；
- 选中焊缝；
- 同时高亮 CAD 视图和点云视图中的同一条焊缝；
- 删除选中焊缝；
- 取消正在进行的选面操作；
- CAD 更换时清空全部焊缝。

### 4.9.1 焊缝起点与方向

焊缝起焊方向此前由 OpenCascade 交线边的参数顺序决定，结果不固定。现把起点定义为 `points` / `segments` 的顺序本身：

- 设定起点：选中焊缝后点击“设定起点”，按住 `Ctrl` 在三维视图中单击起点端，按连通链重排并反转；
- 反转方向：整体倒序；
- 映射与后续轨迹取点自动继承该方向；
- CAD 与点云视图绘制青色起点球标和走向箭头，列表行以 ▶ 标记；
- 已映射的焊缝在改动方向后，用当前匹配变换重建映射。

默认颜色：

- 未选 CAD 焊缝：绿色；
- 选中 CAD 焊缝：洋红色；
- 未选映射焊缝：橙黄色；
- 选中映射焊缝：洋红色。

### 4.10 焊缝刚性映射

入口：右侧“焊缝映射”。

前置条件：

- 焊缝列表中已选中一条焊缝；
- 最新模型匹配执行成功；
- 最新结果必须为 `Pass`；
- 自匹配完成后 CAD 和扫描点云没有被替换。

行为：

- 验证 `T_final` 为有限、齐次、正交且行列式为正的刚性矩阵；
- 对焊缝采样点和每个线段端点执行相同刚性变换；
- 保持焊缝名称、编号、长度、采样点数量和线段数量；
- 在点云视图显示映射后的三维管道；
- 不做最近点吸附；
- 不修改焊缝几何来适应扫描缺失。

### 4.11 焊缝轨迹规划与执行

入口：菜单“执行”。

前置条件（全部满足才能下发运动）：

- 点云为基坐标点云（`CloudFrame::RobotBase`），手眼标定有效；
- 已选中焊缝，且最新匹配结果为 `Pass`；
- 机械臂在线且空闲（没有扫描、轨迹或匹配在运行）；
- “移动至焊缝起点上方”还要求该焊缝已设定起点并已映射。

`WeldPathPlanner` 是纯几何模块，将基坐标下的有序焊缝折线转为 TCP 目标序列：

```text
接近(起点上方 30 mm) → 下降(起点) → 沿焊缝各折点 → 退出(终点上方) → 返回(拍摄起点，可选)
```

- 合并间距小于 0.5 mm 的相邻点；三点夹角偏离直线不足 0.5° 时删去中间点；
- 姿态全程调平（Rx 180 / Ry 0 / Rz 取航向），末端偏离竖直超过 30° 时拒绝；
- 返回段只在有扫描记录时生成：竖直抬到退出点与起点中的较高处 → 水平平移并转姿态 → 竖直下降到位，避免斜穿工件；空走与沿焊缝执行都会返回；
- 中途失败或按 Esc 只停机，不自动返回。

`WeldPathController` 以工具 1、基坐标逐段下发 `MoveL`，每段到位后再发下一段；失败或取消即停机。菜单项：

| 菜单项 | 行为 |
| --- | --- |
| 移动至焊缝起点上方（30 mm） | 只移动到起点接近点，用于核对起点位置与标定链 |
| 焊缝空走 | 整条轨迹抬高 20 mm，用于核对路径 |
| 沿焊缝执行 | TCP 落在焊缝上；工具 1 的 Z 值已含 10 mm 安全余量 |
| 停止轨迹运动（Esc） | 立即停机 |

安全保护：焊缝最高点比当前 TCP 高出 100 mm 以上视为标定方向错误并拒绝执行。未做逆解预检，不可达点由控制器在对应段报错停机。

## 5. 输入与输出

### 5.1 输入

| 输入 | 格式 | 必须条件 |
| --- | --- | --- |
| CAD 模型 | STEP/STP | 有效实体、尺寸有效、可三角化 |
| 扫描点云 | PLY/PCD | 至少包含 100 个有效点 |
| 相机帧 | 海康线轮廓 `Profile/ABC16` | Mv3dLp SDK、设备和手眼标定参数正确 |
| 机械臂状态与运动 | 法奥 3.9.3 控制器（20003/20004/8080 端口） | SDK 版本与控制器 web 版本一致 |
| 手眼标定 | exe 同目录 `calibration.json` | 外参、轴映射和时间偏置有效 |
| 选面操作 | 两个不同 CAD 面 | 两个面存在有效交线 |

### 5.2 内部输出

| 输出 | 类型 | 说明 |
| --- | --- | --- |
| `CadModelData` | CAD 数据 | 形状、面、网格、采样点和尺寸 |
| `MatchResult` | 配准结果 | `T_final`、指标、判定和诊断 |
| `WeldSeamData` | 焊缝数据 | 采样点、线段、长度和标识 |
| `ScanResult` / 点云 | 扫描结果 | 拼接后的深度图，基坐标或传感器坐标 |
| `WeldPathPlan` | 轨迹 | TCP 目标序列，下发给机械臂 |
| 对齐 CAD | 可视化结果 | 半透明叠加，不写入外部文件 |
| 映射焊缝 | 可视化结果 | 刚性变换后的焊缝，不写入外部文件 |

当前版本没有提供以下持久化输出：

- 配准矩阵导出文件；
- 对齐点云或 CAD 导出文件；
- 焊缝坐标导出文件；
- 工程项目文件；
- 用户配置文件（`calibration.json` 除外，它由程序读取，首次运行时自动生成模板）。

## 6. 功能边界

当前不包含：

- 非刚性配准；
- 自动尺度估计或单位转换；
- 镜像模型匹配；
- 焊缝向扫描最近表面的二次吸附；
- 焊接工艺参数（电流、电压、送丝速度）、焊枪摆动与法向跟踪；
- 逆解可达性预检与碰撞检测；
- 焊缝质量检测；
- 结果文件保存与恢复；
- 撤销/重做；
- 多 CAD、多点云批处理。

## 7. 正确使用原则

1. CAD 和点云必须表示同一零件。
2. CAD 和点云必须使用同一长度单位。
3. 点云可以残缺，但必须保留足够的非对称结构或高辨识度特征。
4. 大面积平面、圆柱对称和重复结构容易产生多解；多解不再阻断结果，必须查看日志和对齐 CAD 复核。
5. 只有基坐标点云才能驱动机械臂；传感器坐标点云的匹配和映射结果只用于显示。
6. 映射焊缝的精度不会高于模型匹配精度，也不会高于手眼标定精度。
7. 任何 CAD 或点云替换都会使旧匹配结果失效。
8. 首次执行任何新焊缝前，先用“移动至焊缝起点上方”和“焊缝空走”核对。
