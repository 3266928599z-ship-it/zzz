# 算法详细说明

## 1. 算法总览

项目算法可分为六条链路：

1. CAD 几何读取、三角化和表面采样；
2. 扫描点云读取、清理和工件提取；
3. CAD 与残缺扫描点云的多候选刚性配准；
4. CAD 焊缝生成与刚性映射；
5. 线激光轮廓拼接与基坐标点云生成（第 21 节）；
6. 焊缝折线到机械臂 TCP 轨迹的规划（第 22 节）。

模型匹配的完整推导、KaTeX 公式、质量评分和调参方法见
[11-模型匹配算法原理与实现详解](11-模型匹配算法原理与实现详解.md)。
不支持数学公式渲染的阅读器可使用
[11A-纯文本兼容版](11A-模型匹配算法原理与实现详解-纯文本兼容版.md)。

模型匹配的基本假设：

- CAD 与扫描是同一物体；
- 两者尺度一致；
- 两者之间只存在旋转和平移；
- 扫描允许残缺、噪声和部分场景干扰；
- 不允许镜像、缩放、剪切或非刚性形变。

## 2. 坐标和刚性变换

使用齐次坐标：

```text
       [ R  t ]
T  =   [ 0  1 ]
```

其中：

- `R` 为 3×3 旋转矩阵；
- `t` 为 3×1 平移向量；
- `R^T R = I`；
- `det(R) = +1`。

内部配准主要计算：

```text
p_cad = T_scan_to_cad * p_scan
```

最终返回：

```text
T_final = inverse(T_scan_to_cad)
p_scan = T_final * p_cad
```

`T_final` 用于：

- 将 CAD 采样点叠加到扫描视图；
- 将 CAD 焊缝映射到扫描坐标系。

## 3. STEP 模型处理

实现位置：`StepModelLoader.cpp`。

### 3.1 STEP 读取

使用：

```text
STEPControl_Reader
```

步骤：

1. `ReadFile()`；
2. `TransferRoots()`；
3. `OneShape()`；
4. 检查形状非空。

### 3.2 尺寸估计

计算包围盒：

```text
d = sqrt((xmax-xmin)^2 + (ymax-ymin)^2 + (zmax-zmin)^2)
```

该对角线用于：

- 三角化精度；
- CAD 表面采样间距；
- 模型匹配体素尺寸；
- 坐标轴和焊缝管道显示尺度。

### 3.3 三角化

线性偏差：

```text
linearDeflection = max(d * 0.001, 0.01)
```

角度参数：

```text
0.5 rad
```

三角化后：

- 顶点转换为 PCL 点；
- 三角形转换为 `pcl::Vertices`；
- 每个三角形记录其所属 CAD 面编号。

`cellToFaceMap` 用于把 VTK 拾取到的三角单元重新映射为 OpenCascade 面。

### 3.4 表面采样

采样间距：

```text
sampleSpacing = max(d * 0.005, 0.25)
```

每个三角形采样数：

```text
sampleCount = clamp(ceil(area / sampleSpacing^2), 1, 1000)
```

三角形内使用确定性的低差异参数序列生成重心采样位置：

```text
u = frac((i+1) * 0.6180339887)
v = frac((i+1) * 0.4142135624)
```

若 `u + v > 1`，将二者镜像到三角形内部。

目的：

- 避免只使用网格顶点造成密度受三角化拓扑影响；
- 让配准点更均匀覆盖 CAD 表面。

## 4. 点云文件清理

实现位置：`PointCloudLoader.cpp`。

步骤：

1. 根据扩展名调用 PLY 或 PCD 读取器；
2. 删除 NaN 和 Inf；
3. 删除平方距离小于 `1e-12` 的近原点点；
4. 将点云设为无组织点云：
   - `width = points.size()`；
   - `height = 1`；
   - `is_dense = true`；
5. 计算包围盒对角线。

文件读取不进行体素降采样，确保显示和后续处理仍可访问全部有效点。

## 5. 模型匹配预处理

实现位置：`ModelMatchWorker::preprocess()`。

### 5.1 动态体素尺寸

```text
leaf = max(CAD_diagonal * leafSizeFactor, 0.5)
```

默认：

```text
leafSizeFactor = 0.01
```

设计目的：

- 参数随工件尺寸缩放；
- 避免体素过小导致内存和时间过高；
- 最小体素 0.5，按毫米单位理解。

### 5.2 体素降采样

CAD 和扫描均首先执行 `pcl::VoxelGrid`。

原因：

- 原始点云可能有数百万点；
- 粗配准和法向计算不需要原始密度；
- 降采样必须早于 SOR、聚类和特征提取。

### 5.3 统计离群点滤波

仅用于扫描，在体素降采样之后、支撑平面剔除之前执行。

参数：

```text
MeanK = 50
StddevMulThresh = 1.0
```

目的：删除离主体较远的飞点，同时避免支撑面下方的噪声干扰后续的单侧性判定。

### 5.4 支撑平面剔除

仅用于扫描。

旧实现是“RANSAC 最大平面且占比 > 15% 即删除”，风险是最大平面可能就是工件顶面。当前实现改为只删除**支撑平面**（底板或工作台），判据是单侧性：支撑面下方几乎没有点，上方有物体。

候选搜索（最多 4 次）：

1. 在剩余点上做 `SACMODEL_PERPENDICULAR_PLANE` RANSAC，法向与 `MatchConfig::scanUpAxis` 夹角不超过 30°，最大迭代 500，距离阈值 `1.25 * leaf`；
2. 候选平面点数不少于 `max(50, 5% 点数)`，否则停止；
3. 法向归一化后统一朝向 `scanUpAxis`；
4. 在**完整点云**（不是剩余点）上统计该平面两侧点比例：

```text
below: 有符号距离 < -1.5 * leaf
above: 有符号距离 >  2.0 * leaf
```

5. 判定为支撑面：

```text
belowRatio < 2%  且  aboveRatio >= 5%
```

6. 记录平面沿 `scanUpAxis` 的平均高度；若多个候选都是支撑面，取高度最低者；
7. 把该候选的内点移出，继续搜索下一个候选。

找到支撑面后，保留有符号距离 `> 1.25 * leaf` 的点（连同平面以下的残余噪声一起删除），要求剩余点不少于 100，否则放弃剔除。找不到合格平面时保留全部点，日志提示“未识别到支撑平面”。

工件顶面下方还有底板，会有大量点在其下方，过不了单侧性检查，因此不会被误删。

`scanUpAxis` 的含义：扫描点云坐标系中朝向相机的方向。海康线激光离相机越近 Z 越大，故为 +Z；基坐标点云下为基座竖直向上方向，同样为 +Z。

### 5.5 欧式聚类

仅用于扫描。

参数：

```text
ClusterTolerance = 2.0 * leaf
MinClusterSize = 40
MaxClusterSize = 全部点数
```

每个连通区域计算：

- 点数；
- 对角线；
- 相对 CAD 尺寸比：

```text
ratio = clusterDiagonal / cadDiagonal
```

合理尺寸区间：

```text
0.45 <= ratio <= 1.35
```

聚类评分：

```text
score = log(1 + pointCount)
        - 2 * abs(log(max(ratio, 0.001)))
        + (plausibleSize ? 3 : 0)
```

选择分数最高且至少 100 点的区域。

该算法同时偏好：

- 点数多；
- 尺寸接近 CAD；
- 不过小的夹具碎片；
- 不过大的整场景底板。

误删回退：若本次已剔除支撑平面，且所选主体尺寸比 `< 0.45`（或没有选出主体），则对**未剔除平面**的点云重新聚类；若回退结果尺寸比在 0.45~1.35 内，说明删掉的很可能是工件表面，改用回退结果并写日志。

若主体尺寸比大于 1.08，日志提示可能仍含夹具、圆环或尺度错误。

### 5.6 法向估计

使用 `NormalEstimationOMP`。

```text
RadiusSearch = 3.0 * leaf
```

过滤：

- 点必须有限；
- 法向必须有限；
- 法向平方长度至少 0.25；
- 通过后归一化。

### 5.7 最小点数保护

原始 CAD、扫描和预处理后的两者均至少需要 100 点。

目的：

- 避免特征估计和配准在退化输入上崩溃；
- 提供清晰错误信息。

## 6. 关键点与 FPFH

实现位置：`extractEdgeFeatures()`。

### 6.1 主曲率

使用 `PrincipalCurvaturesEstimation`：

```text
RadiusSearch = 4.0 * leaf
```

显著性：

```text
saliency = |pc1| + |pc2| + |point.curvature|
```

按显著性降序排列。

### 6.2 关键点数量

```text
requested = pointCount * clamp(edgePercentile, 0.15, 0.45)
minimum   = min(400, pointCount)
keepCount = min(3000, max(minimum, requested))
```

默认 `edgePercentile = 0.25`。

### 6.3 FPFH 描述子

FPFH 搜索半径：

```text
6.0 * leaf
```

关键点作为输入点，完整降采样点云作为搜索表面与法向来源。

过滤所有直方图中存在非有限值的描述子。

若有效描述子少于 100：

1. 改用最多 2000 个均匀关键点；
2. 再次计算；
3. 若仍少于 100，则直接对完整点云计算。

该回退路径提高低曲率或残缺点云上的可用性。

## 7. 粗配准候选生成

实现位置：`coarseRegistration()`。

粗配准不是只依赖一种方法，而是合并：

- FPFH + Sample Consensus Prerejective；
- PPF；
- PCA 确定性姿态。

所有候选都必须是右手系刚性变换，不允许 `det(R) < 0`。

### 7.1 FPFH + SAC

启用条件：

- CAD 和扫描关键点均至少 100；
- 特征数量与关键点数量一致。

参数：

```text
运行次数                  max(8, sacRuns)
MaximumIterations         25000
NumberOfSamples           3
CorrespondenceRandomness  18
SimilarityThreshold       0.75
MaxCorrespondenceDistance 4.0 * leaf
InlierFraction            clamp(sacInlierFrac, 0.08, 0.30)
```

默认：

```text
sacRuns = 8
sacInlierFrac = 0.15
```

### 7.2 PPF

目的：补充局部场景和几何点对投票候选。

模型点数上限：

```text
500
```

场景点数上限：

```text
1400
```

法向处理：

- CAD 法向朝模型质心外侧统一；
- 扫描法向使用原方向和整体反向两个 pass。

PPF 参数：

```text
角度离散                 12°
距离离散                 1.5 * leaf
SceneReferenceSampling   8
PositionClustering       4.0 * leaf
RotationClustering       15°
每个 pass 最多取         5 个姿态
```

PPF 失败不会终止整个匹配，会记录日志并继续 FPFH/PCA。

### 7.3 PCA 候选

计算 CAD 和扫描的：

- 质心；
- 协方差；
- 主轴。

枚举：

- 6 种轴排列；
- 每轴正负方向组合；
- 仅保留行列式接近 +1 的旋转。

理论组合较多，经过右手系约束后形成 24 个有效刚性姿态。

PCA 的作用：

- 提供确定性候选；
- 在 FPFH 因残缺或重复平面失效时兜底。

风险：

- 对称工件容易产生多个等价主轴方向；
- 必须依靠后续候选评分和 ICP 复核。

## 8. 粗候选评分

每个候选把扫描变换到 CAD 坐标系。

### 8.1 对应距离

最大距离：

```text
4.0 * leaf
```

最低扫描覆盖：

```text
12%
```

### 8.2 关键特征最低门槛

若存在可用特征：

```text
featureOverlap >= 8%
```

关键点对应距离：

```text
3.0 * leaf
```

法向绝对点积：

```text
>= 0.45
```

### 8.3 空间覆盖最低门槛

```text
spatialCoverage >= 12%
```

空间覆盖将 CAD 包围盒划分为 `3 × 3 × 3 = 27` 个单元，并统计：

- 被 CAD 占据的单元；
- 得到扫描支持的单元；
- 法向主方向 X/Y/Z 的覆盖。

最终：

```text
spatialCoverage = 0.65 * cellCoverage
                + 0.35 * normalBinCoverage
```

### 8.4 截断 RMSE

仅保留残差最小的 70%，降低离群点影响：

```text
trimmedRmse = sqrt(mean(best 70% squared distances))
```

### 8.5 粗候选综合分数

分数越小越好：

```text
score =
    trimmedRmse
  + (1 - scanOverlap)       * leaf * 2.0
  + (1 - featureOverlap)    * leaf * 2.5
  + (1 - spatialCoverage)   * leaf * 1.5
  + (1 - normalConsistency) * leaf * 0.75
  - min(cadOverlap, 0.40)   * leaf * 0.75
```

无可用特征时不添加特征惩罚。

### 8.6 候选去重

若两个候选满足：

```text
旋转差 < 8°
平移差 < 3.0 * leaf
```

则视为重复。

最多保留 6 个不同候选。

## 9. CAD 引导自动裁剪

目的：从仍可能包含夹具、圆环或残块的扫描主体中，依据每个候选姿态进一步提取与 CAD 接近的点。

实现：`extractCadGuidedScan()`。

步骤：

1. 将扫描按候选变换到 CAD；
2. 对每个扫描点查找最近 CAD 点；
3. 检查距离；
4. 检查法向一致性；
5. 保留原扫描坐标中的对应点。

法向绝对点积最低：

```text
0.15
```

三层距离：

```text
宽松：6.0 * leaf
中等：3.5 * leaf
严格：2.5 * leaf
```

每一层裁剪后运行一次点到点 ICP。

最低保留点数：

```text
max(250, 原扫描降采样点数 * 10%)
```

若任一层低于该门槛，该候选被淘汰。

## 10. 精配准阶段 A：点到点 ICP

实现：`fineRegistrationA()`。

参数：

```text
MaximumIterations          icpMaxIterA，默认 50
MaxCorrespondenceDistance  3.0 * leaf
RANSACOutlierThreshold     1.5 * leaf
DistanceRejector           2.0 * leaf
TransformationEpsilon      1e-7
EuclideanFitnessEpsilon    1e-6
```

若 ICP 不收敛或矩阵非有限：

- 保留输入姿态；
- 适应度设为无穷；
- 不直接崩溃。

## 11. 自动裁剪候选综合评分

每个完成三层裁剪和 ICP 的候选计算：

- 扫描覆盖；
- CAD 支持；
- 法向一致；
- 特征覆盖；
- 空间覆盖；
- 裁剪保留比例；
- RMSE。

分数：

```text
quality =
    rmse
  + (1 - overlap)           * leaf * 2.0
  + (1 - featureOverlap)    * leaf * 3.0
  + (1 - spatialCoverage)   * leaf * 2.0
  + (1 - min(guidedRatio / 0.65, 1)) * leaf * 1.5
  + (1 - normalConsistency) * leaf * 0.50
  - min(reverseOverlap, 0.40) * leaf * 0.75
```

选择分数最低者。

若第二名与第一名之比：

```text
secondScore / bestScore < ambiguityRatio
```

则标记为多解歧义。默认 `ambiguityRatio = 1.10`。

## 12. 精配准阶段 B：鲁棒点到面 ICP

实现：`fineRegistrationB()`。

### 12.1 对应筛选

最大距离：

```text
2.0 * leaf
```

法向处理：

- 若点积为负，翻转目标法向；
- 最终余弦至少 0.1。

### 12.2 点到面残差

对源点 `p`、目标点 `q`、目标法向 `n`：

```text
r = -n · (p - q)
```

小位姿增量：

```text
x = [ωx, ωy, ωz, tx, ty, tz]^T
```

雅可比：

```text
J = [(p × n)^T, n^T]
```

累积正规方程：

```text
ATA += w * J^T * J
ATb += w * J^T * r
```

### 12.3 Huber 鲁棒权重

```text
delta = leaf
```

```text
w_huber = 1                    distance <= delta
w_huber = delta / distance     distance > delta
```

最终权重：

```text
w = w_huber * normalCosine
```

远距离点和法向不一致点影响更小。

### 12.4 数值稳定

至少需要 10 对有效对应。

对角阻尼：

```text
lambda = max(maxDiagonal(ATA) * 1e-6, 1e-8)
ATA_diagonal += lambda
```

使用 Eigen LDLT 求解。

目的：

- 局部扫描常接近平面；
- 某些自由度约束弱；
- 阻尼避免奇异矩阵导致异常退出。

### 12.5 步长限制

单次最大旋转：

```text
0.05 rad，约 2.86°
```

单次最大平移：

```text
max(leaf, 0.001)
```

### 12.6 收敛条件

```text
rotationIncrement < 1e-4
translationIncrement < 1e-4
```

最大迭代：

```text
icpMaxIterB，默认 50
```

## 13. 精配准回退

点到面 ICP 并非无条件接受。

若最终综合质量：

```text
finalQuality > bestStageAQuality + 0.10 * leaf
```

或质量非有限，则：

- 回退到多候选点到点 ICP 的最佳姿态；
- 恢复阶段 A 的指标；
- 将 `convergedStageB` 设为 false。

该机制防止点到面 ICP 在局部平面上滑向错误局部极值。

## 14. 质量指标

对应距离门槛：

```text
2.5 * leaf
```

### 14.1 扫描覆盖率

```text
overlap = 有效扫描对应点 / 扫描点总数
```

表示当前提取出的扫描工件有多少能落在 CAD 附近。

### 14.2 CAD 反向支持率

```text
reverseOverlap = 被扫描支持的 CAD 点 / CAD 点总数
```

局部扫描下该指标通常低于扫描覆盖率。

### 14.3 法向一致性

对所有有效对应：

```text
mean(|n_scan · n_cad|)
```

范围 0 到 1。

### 14.4 RMSE

```text
RMSE = sqrt(mean(distance^2))
```

单位与 CAD 相同。

### 14.5 P95 残差

有效对应点距离排序后的 95% 分位值。

相比 RMSE，P95 更容易反映尾部偏差。

### 14.6 关键特征覆盖率

扫描关键点变换后，在 `3 * leaf` 内找到 CAD 关键点，且法向一致至少 0.45 的比例。

### 14.7 空间结构覆盖率

27 个空间网格单元覆盖与 3 个法向主轴覆盖的加权结果。

## 15. 结果判定

实现：`classifyResult()`。

### 15.1 直接失败

满足任一条件：

```text
RMSE 非有限
扫描覆盖 < 0.30
CAD 支持 < 0.10
特征覆盖 < 0.15
空间覆盖 < 0.18
法向一致 < 0.45
RMSE > 1.25 * leaf
P95 > 2.0 * leaf
```

### 15.2 不再阻断的情形

下列情形原先判为“需要人工确认”（`NeedsReview`）并禁止焊缝映射，现已取消，只在日志中提示：

```text
存在多解歧义
点到面 ICP 未收敛
扫描覆盖 < 0.55
CAD 支持 < 0.25
特征覆盖 < 0.35
空间覆盖 < 0.40
法向一致 < 0.70
```

此时程序采用得分最高的候选作为结果。对称或多解工件必须由操作员依据对齐 CAD 叠加效果和日志复核。

### 15.3 匹配通过

未触发 15.1 的任一直接失败条件即为 `Pass`。判定只有 `Pass` 和 `Fail` 两种。

## 16. 焊缝生成

实现：`WeldSeamService::createSeam()`。

步骤：

1. 使用 `BRepAlgoAPI_Section(faceA, faceB)`；
2. 构造两个面的交线；
3. 遍历交线上的每条 Edge；
4. 使用 `BRepAdaptor_Curve`；
5. 使用 `GCPnts_AbscissaPoint::Length` 计算长度；
6. 按长度生成采样点。

每条边采样数：

```text
max(int(length / 1.5), 8)
```

保存：

- 采样点；
- 相邻采样点构成的线段；
- 所有边长度之和。

## 17. 焊缝刚性映射

实现：`WeldSeamMapping.cpp`。

### 17.1 矩阵验证

要求：

```text
所有元素有限
底行为 [0, 0, 0, 1]，容差 1e-4
R^T R 接近 I，容差 1e-3
det(R) 接近 1，容差 1e-3
```

因此拒绝：

- 镜像；
- 缩放；
- 剪切；
- 非齐次矩阵；
- NaN/Inf。

### 17.2 点变换

```text
p_scan = T_final * [p_cad, 1]^T
```

同一变换应用到：

- 所有焊缝采样点；
- 所有线段起点；
- 所有线段终点。

### 17.3 保持不变

- ID；
- 名称；
- 总长度；
- 点数；
- 线段数；
- 连续性。

### 17.4 当前不是表面吸附

算法不会搜索最近扫描点，也不会根据扫描缺陷改变焊缝。若后续增加吸附，应作为刚性映射之后的新阶段，并保留原始刚性结果用于对比和回退。

## 19. 算法复杂度与性能

主要开销：

| 阶段 | 主要复杂度/开销 |
| --- | --- |
| 原始点云读取 | 与文件大小和点数线性相关 |
| 渐进显示 | 与全部有效点线性相关 |
| 体素降采样 | 近似线性，受体素哈希影响 |
| 法向/最近邻 | KD-tree 查询，近似 `N log N` |
| FPFH | 与关键点数和邻域大小相关 |
| PPF | 模型点对特征可接近 `O(N²)`，因此限制模型为 500 点 |
| 多候选 ICP | 候选数 × 三层裁剪 × ICP 迭代 |
| 点到面 ICP | 迭代数 × 扫描降采样点数 × 最近邻查询 |

性能控制手段：

- 原始点云先体素降采样；
- 关键点最多 3000；
- PPF 模型 500 点、场景 1400 点；
- 粗候选去重后最多 6 个；
- CAD 引导裁剪逐级减少点；
- 原始共享点云在预处理后释放；
- 点云显示按 100000 点分批。

## 20. 算法调试建议

出现错误结果时，按以下顺序检查：

1. CAD 和扫描单位；
2. 预处理日志中的 CAD、扫描点数和 `leaf`；
3. 聚类尺寸比；
4. 处理后点云是否确实为工件主体；
5. 粗候选报告中的扫描覆盖、特征和空间覆盖；
6. 自动裁剪保留比例；
7. 阶段 A 与阶段 B 的质量变化；
8. 最终 RMSE/P95 是否与体素大小相称；
9. 是否因对称结构被标记为歧义（现在只在日志中提示，不再阻断）；
10. `T_final` 方向是否被正确使用；
11. 点云是否为基坐标点云，`scanUpAxis` 是否与点云坐标系一致；
12. 日志中“平面候选”行：下方/上方比例是否合理，是否出现“疑似误删工件表面，已回退”。

## 21. 线激光轮廓拼接与基坐标点云

实现：`ScanSession`、`ScanController`、`HandEyeConfig`、`PoseMath`。

### 21.1 设备输出

`ImageMode = 4` 下设备返回 `Profile/ABC16`：每点 3 个 `int16`，A=X 编码、B 恒 0、C=Z 编码，空点三分量同为 -32768。换算：

```text
x_mm = A × LSLProfileCoordXUnit / 1000
z_mm = C × LSLProfileCoordZUnit / 1000
```

设备按批输出，每批 20~50 行，批内没有行坐标，时间戳也不可用，所以每行沿运动方向的位置必须由上位机计算。

### 21.2 按行序号补 Y（名义模式）

```text
Y = 全局行序号 × 步距
```

行序号在批次之间连续累加。这要求扫描匀速且 `速度 = 步距 × 行率`，否则 Y 会被均匀拉伸或压缩。

丢批处理：帧号不连续时，按已收帧的平均行数补空行，保持 Y 尺度，缺失区间内是空洞，不会把后续点云前移。帧号跳变未必是真丢批，补齐区间单独记录，收尾时结合实收行率决定是否采用。

首帧只用于确认流已就绪，不计入拼接；机器人位移超过 0.5 mm 后才开始记录。

### 21.3 轨迹模式（沿实测轨迹定 Y）

相机回调与机器人遥测使用同一个单调时钟 `hostClockUs()`。每批到达时刻近似为该批末行的采集时刻，批内第 `r` 行的采集时刻为：

```text
t_r = t_arrive − (rows − 1 − r) × 行周期
行周期 = 1 / 实测行率
实测行率 = (实收行数 − 首批行数) / (末批到达 − 首批到达)
```

再在机器人轨迹采样（时刻、已行进距离、TCP 位姿，每 10 ms 一个）上插值，得到该行的行进距离作为 Y。这样不再依赖“步距 × 行率 = 速度”，加减速段和行率偏离设定值都不会拉伸点云；丢批只留空洞、不移位。

收尾时若实测位移与名义步距偏差超过 5%，采用实测值并写日志。该日志是标定 `scanVelPercent` 的依据（法奥 `MoveL` 的 `vel` 是百分比而非 mm/s）。

### 21.4 基坐标点云

存在有效手眼标定时，对每行：

```text
p_base = T_base_tcp(t) · T_tcp_sensor · M_axis · (x, 0, z)_SDK
```

- `T_base_tcp(t)`：行时刻 `t + timeOffsetUs` 在 TCP 轨迹上的插值，平移线性、姿态四元数 slerp；
- `T_tcp_sensor`：HiCalibrator EIH-N 轮廓线标定结果（固定轴 XYZ，mm / 度），工具 1 激活下标定；
- `M_axis`：SDK 输出轴到手眼标定传感器坐标系的轴置换，默认 X↔Y 互换、Z 取反，必须是行列式为 +1 的正交矩阵；
- `timeOffsetUs`：相机行时刻相对遥测时刻的补偿；
- 空点输出 NaN，转云时跳过。

输出的 x/y/z 直接是基坐标（mm），不受 `reverseY` 和 `yOffsetMm` 影响。

标定无效或轨迹样本不足两点时，回退为传感器坐标点云（`CloudFrame::Sensor`）。基坐标点云下匹配得到的 `T_final` 为 CAD → 基座，焊缝映射结果直接位于基坐标。

### 21.5 标定要点

- 工具坐标 Z 为 250 mm（真实尖端到法兰）；HiCalibrator 原始 `tz = 290.166` 是在工具 Z = 260 时采集的，写入 `calibration.json` 前必须扣除工具长；
- 当前现场值 `tx 42.52 / ty 88.47 / tz 41.82`，由两个已知焊缝起点做平移最小二乘得到，旋转项和 `sensorAxis` 未动；
- 样本不足以支撑约 3° 偏航的修正，补第三个已知点后才能确认；
- 详见 `docs/calibration/README.md`。

## 22. 焊缝轨迹规划

实现：`WeldPathPlanner::planWeldPath()`，纯几何，不访问机械臂。

输入：基坐标下的有序焊缝折线（顺序即焊接方向）与 `WeldPathOptions`。

### 22.1 折线简化

1. 间距合并：相邻点间距 `< minSpacingMm`（0.5 mm）时舍弃后点；末点始终保留，避免终点被吞；
2. 共线删除：对连续三点，若前后两段方向夹角余弦 `>= cos(0.5°)`，删去中间点。

简化后少于 2 点则拒绝（有效长度过短）。

### 22.2 路点序列

姿态固定为 `Rx 180 / Ry 0 / Rz heading`（工具 Z 竖直向下），位置取折线点加整体抬高 `liftMm`：

```text
Approach  起点 + (0, 0, approachMm)
Descend   起点
Seam ...  各折点
Retreat   终点 + (0, 0, approachMm)
Return …  （可选）返回拍摄起点
```

记录焊缝长度、最高/最低 Z、线段数，以及焊缝终点在路点中的下标 `seamEndIndex`（追加返回段后末尾不再是焊缝终点）。

### 22.3 返回段

仅在有扫描记录（`needReturn`）时生成。设 `safeZ = max(退出点 Z, 返回位姿 Z)`：

1. 若 `safeZ` 高于退出点 0.5 mm 以上，先竖直抬到 `safeZ`；
2. 在 `safeZ` 水平平移并转到拍摄姿态；
3. 若 `safeZ` 高于返回位姿 0.5 mm 以上，再竖直下降到位。

目的：避免直线斜穿工件。

### 22.4 执行与保护

`WeldPathController` 以工具 1、基坐标逐段 `MoveL`，每段到位后再发下一段，失败或取消即停机。界面层在下发前检查：

- 当前 TCP 偏离竖直不超过 30°；
- 焊缝最高点（含抬高量）不比当前 TCP Z 高出 100 mm 以上，否则视为点云或标定方向反了而拒绝；
- 点云必须为基坐标点云，匹配结果必须为 `Pass`。

未做逆解可达性预检与碰撞检测。
