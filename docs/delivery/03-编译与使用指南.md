# 编译与使用指南

## 1. 适用范围

本文档说明如何在新的 Windows 开发环境中配置、编译、运行和操作 `dianyun`。

当前项目文件包含开发机绝对路径，不能保证复制到任意计算机后直接编译。首次迁移必须完成路径检查。

## 2. 当前已验证环境

| 组件 | 当前配置 |
| --- | --- |
| 操作系统 | Windows 10/11 x64 |
| Visual Studio | Visual Studio 2022 Community |
| MSVC 工具集 | v143 |
| Windows SDK | 10.0.26100.0 |
| C++ 标准 | C++17 |
| Qt | 6.10.1，MSVC 2022 x64 |

## 3. 必需软件

### 3.1 Visual Studio 2022

安装工作负载：

- 使用 C++ 的桌面开发；
- Windows 10/11 SDK；
- MSVC v143 x64/x86 生成工具；
- C++ CMake 工具可选。

### 3.2 Qt 6.10.1

安装：

- Qt 6.10.1；
- MSVC 2022 64-bit；
- Qt VS Tools 扩展。

在 Visual Studio 中：

1. 打开 `扩展 -> 管理扩展`；
2. 安装 Qt Visual Studio Tools；
3. 打开 `扩展 -> Qt VS Tools -> Qt Versions`；
4. 添加 Qt 路径 `E:\Qt\6.10.1\msvc2022_64` 或新机器上的实际路径；
5. 名称应设置为项目引用的 `6.10.1_msvc2022_64`，或同步修改 `.vcxproj` 中的 `<QtInstall>`。

### 3.3 PCL、VTK、Eigen、OpenCascade

当前工程是混合依赖布局：

- 头文件主要来自 `E:\vcpkg-master\installed\x64-windows\include`；
- PCL Release 库路径来自 `E:\PCL 1.15.1`；
- Qt 来自独立 Qt 安装；
- 海康 Mv3dLp 与法奥 SDK 的头文件和导入库已收录在 `dianyun/third_party/`，通过 `$(Mv3dLpRoot)`、`$(FairinoSdkRoot)` 引用，不依赖绝对路径。

迁移时有两种方案：

#### 方案 A：复现当前目录

优点：改动最少。

要求：

- 按当前路径安装或复制依赖；
- 保持版本一致；
- 检查所有 DLL 能被复制到输出目录。

#### 方案 B：统一使用 vcpkg

优点：长期更易维护。

要求：

- 使用同一 vcpkg 根目录；
- 安装 PCL、VTK、Eigen、OpenCascade；
- 移除项目中的多套 PCL/VTK 路径；
- 重新验证 ABI、Debug/Release 库和 Qt VTK 支持。

本次交付未完成依赖统一，建议迁移后单独建立一个依赖整理分支。

### 3.4 海康 Mv3dLp SDK

仓库已收录：

```text
dianyun/third_party/mv3dlp/include/Mv3dLpApi.h
dianyun/third_party/mv3dlp/include/Mv3dLpDefine.h
dianyun/third_party/mv3dlp/include/Mv3dLpImgProc.h
dianyun/third_party/mv3dlp/lib/Mv3dLp.lib
```

工程通过 `<Mv3dLpRoot>$(ProjectDir)..\third_party\mv3dlp</Mv3dLpRoot>` 引用，并链接 `Mv3dLp.lib`。

需要注意：

- 仓库**没有**收录 `Mv3dLp.dll`，工程也没有对应的自动部署目标；
- 运行时 DLL 的来源和放置位置（系统 `PATH` 或 exe 同目录）在仓库中没有记录，迁移到新机器时需确认并补充；
- 确保相机驱动和网络配置正常；
- 实测相机型号 MV-DP2240-01H，SDK 1.3.3.3。

没有相机硬件时仍可编译，但运行时需要 Mv3dLp 运行库。

### 3.5 法奥机械臂 SDK

仓库已收录 `fairino-cpp-sdk` 的 **3.9.3** 分支（SDK V2.3.3.0）：

```text
dianyun/third_party/fairino-3.9.3/include/robot.h
dianyun/third_party/fairino-3.9.3/include/robot_error.h
dianyun/third_party/fairino-3.9.3/include/robot_types.h
dianyun/third_party/fairino-3.9.3/lib/fairino.lib
dianyun/third_party/fairino-3.9.3/lib/fairino.dll
dianyun/third_party/fairino-3.9.3/LICENSE
```

约束：

- SDK 版本必须与控制器 web 版本对齐。现场控制器为 FR10，web 版本 `v3.9.3.1`，只能使用 3.9.3 分支；
- 不要换回 v1.x（`cobotAPI.lib`）：其 `MoveL` / `GetInverseKinRef` 协议与该固件不匹配，响应解析会抛异常；
- 不要换成带 `FRCNDEClient` 的更新版本，它依赖 20005 端口；
- 本 SDK 只使用 20003（XML-RPC）、20004（状态流）、8080（命令）端口；
- 仓库只收录 Release 库，Debug 配置不定义 `DIANYUN_ROBOT_SDK`，`RobotWorker` 为空实现，点击连接会提示当前构建未启用机械臂 SDK；
- `fairino.dll` 由 `DeployFairinoRuntime` 目标在 Release 构建后自动复制到 exe 同目录；
- 库放在 `lib/` 而非 `lib/Release/`，因为 `.gitignore` 的 `[Rr]elease/` 规则会排除后者。

## 5. 配置检查

在编译前检查 `dianyun/dianyun/dianyun.vcxproj`：

### 5.1 平台

```text
Configuration: Release
Platform:      x64
Toolset:       v143
```

### 5.2 Qt

```xml
<QtInstall>6.10.1_msvc2022_64</QtInstall>
```

### 5.3 vcpkg

```xml
<VcpkgRoot>E:\vcpkg-master\</VcpkgRoot>
<VcpkgTriplet>x64-windows</VcpkgTriplet>
```

### 5.4 编译选项

Release 当前启用：

- `/std:c++17`；
- `/utf-8`；
- OpenMP；
- AVX；
- 多处理器编译；
- SDL 检查；
- 一致性模式。

### 5.5 宏

关键宏：

```text
PCL_NO_PRECOMPILE
BOOST_USE_WINDOWS_H
NOMINMAX
_CRT_SECURE_NO_WARNINGS
PCL_SILENCE_MALLOC_WARNING
DIANYUN_ROBOT_SDK          （仅 Release 配置定义）
```

### 5.6 构建后部署目标

Release 构建后自动执行：

| 目标 | 作用 |
| --- | --- |
| `DeployQtRuntime` | 用工程自身的 `QtInstallDir` 调 `windeployqt --force --no-translations --no-system-d3d-compiler`，部署同版本 Qt 核心库与插件 |
| `DeployFairinoRuntime` | 复制 `fairino.dll` 到 exe 同目录 |

`DeployQtRuntime` 存在的原因：工程链接 Qt 6.10.1，但 vcpkg 的 `applocal` 在每次构建后会把 `E:\vcpkg-master` 下的 Qt 6.10.0 拷入输出目录，且不部署 Qt 插件，导致核心库与 `platforms/qwindows.dll` 小版本不一致，运行时报 `no Qt platform plugin could be initialized`。必须加 `--force`，否则 vcpkg 拷入的 DLL 时间戳更新，windeployqt 会判定为最新而跳过。

若启动时仍报该错误，检查输出目录中 Qt DLL 与插件的版本是否一致。

## 10. 标准操作流程

### 10.1 只进行模型匹配

1. 点击“导入三维模型”；
2. 选择 STEP/STP；
3. 确认日志显示 CAD 采样点数；
4. 点击“导入点云模型”；
5. 选择 PLY/PCD；
6. 等待后台加载完成；
7. 等待状态栏显示“点云就绪”；
8. 点击“模型匹配”；
9. 等待预处理、粗配准、精配准和判定完成；
10. 查看状态和叠加结果。

### 10.2 使用相机点云

单帧拍摄（传感器坐标，只能用于显示和匹配，不能驱动机械臂）：

1. 在“通信”菜单连接相机，确保没有其他软件占用设备；
2. 点击“开始拍摄”；
3. 等待日志显示采集和拼装完成；
4. 等待完整点云显示完成；
5. 导入对应 CAD；
6. 点击“模型匹配”。

机械臂扫描（基坐标点云，可驱动机械臂）：

1. 在“通信”菜单连接相机与机械臂，确认两个状态指示灯均为绿色；
2. 确认 `calibration.json` 有效（必要时用“通信 → 重新加载手眼标定”）；
3. 确认扫描路径上无障碍物，工件已摆放到位；
4. 菜单“执行 → 开始扫描采集”（Ctrl+Shift+S），在确认对话框核对当前位姿与扫描位姿；
5. 机械臂依次完成抬升（已在安全高度则跳过）、调平到基坐标 Z = 150 mm（Rx 180 / Ry 0 / Rz 90）、起流、沿工具 X 轴（基坐标 +Y）直线扫描 200 mm（约 7 秒）、停流并退回扫描起点；
6. 日志中检查点云平均 Z 是否低于扫描起点 TCP Z（否则 `sensorAxis` 可能反了）；
7. 导入对应 CAD，点击“模型匹配”；
8. 需要中止时使用“执行 → 取消扫描”。

“开始扫描采集”仅在相机与机械臂都在线、且没有匹配或点云加载任务运行时可用；点云仍在分批显示时会提示稍候。

### 10.3 创建焊缝

1. 导入 CAD；
2. 点击“新建焊缝”；
3. 按住 `Ctrl` 单击第一个 CAD 面；
4. 按住 `Ctrl` 单击第二个不同 CAD 面；
5. 查看焊缝列表、长度和管道显示；
6. 选中焊缝，点击“设定起点”，按住 `Ctrl` 在三维视图中单击起点端；需要时点击“反转方向”；
7. 确认 CAD 视图中出现青色起点球标与走向箭头，列表行出现 ▶。

### 10.4 映射焊缝

1. 完成模型匹配；
2. 确认状态为“匹配通过”，并目视检查对齐 CAD 的叠加效果；
3. 在焊缝列表选择一条焊缝；
4. 点击“焊缝映射”；
5. 在点云视图查看映射管道和起点标记；
6. 切换焊缝列表，确认两个视图同步高亮。

### 10.5 机械臂执行焊缝轨迹

前提（四项全部满足，轨迹类菜单项才可用）：

- 点云为基坐标点云（10.2 的机械臂扫描）；
- 手眼标定有效，机械臂在线且空闲（没有扫描、轨迹或匹配在运行）；
- 已选中焊缝，且最新匹配结果为 `Pass`；
- 对“移动至焊缝起点上方”，还要求该焊缝已设起点并已映射。

建议顺序：

1. “执行 → 移动至焊缝起点上方（30 mm）”：目测尖端是否落在焊缝起点正上方 30 mm；偏差大于 1~2 mm 时先复核 `sensorAxis` 与手眼外参；
2. “执行 → 焊缝空走”：整条轨迹抬高 20 mm，核对路径；
3. “执行 → 沿焊缝执行”：TCP 落在焊缝上，结束后自动返回拍摄起点；
4. 任何时刻按 `Esc` 或“停止轨迹运动”立即停机，中途停机不会自动返回。

安全提示：软件未做逆解预检与碰撞检测，不可达点由控制器在对应段报错停机；焊缝最高点比当前 TCP 高出 100 mm 以上时会被拒绝。执行时现场人员必须能随时触达急停。

## 11. 如何理解结果

### 匹配通过

- 可显示对齐 CAD；
- 可执行焊缝映射；
- 多解歧义和点到面 ICP 未收敛不再阻断结果，只在日志中提示；对称工件必须人工检查日志与叠加效果；
- 仍建议从多个视角人工检查边缘、圆弧和端面。

### 匹配质量不足

- 不显示对齐 CAD；
- 不允许焊缝映射；
- 检查单位、工件、支撑平面剔除、聚类、残缺程度和特征。

## 12. 清理与重新测试

无需清理即可重新导入。

行为：

- 导入新 CAD：清空焊缝、旧匹配和旧映射；
- 导入新点云：保留 CAD 焊缝，但清空旧匹配和旧映射；
- 删除焊缝：同步删除 CAD 和点云视图 actor；
- 匹配运行期间：导入与拍摄按钮禁用；
- 扫描运行期间：开始扫描、轨迹类菜单项和“重新加载手眼标定”禁用；轨迹运行期间同样禁用，仅“停止轨迹运动”可用。

## 13. 迁移到新计算机的验收

迁移完成后依次验证：

1. 解决方案无卸载项目；
2. Release x64 编译成功；
3. 构建后部署目标执行成功，程序可启动；
4. 测试程序输出通过；
5. STEP 能导入；
6. PLY/PCD 能后台导入；
7. 点云全部显示；
8. 模型匹配能运行完成；
9. 焊缝能创建并设起点；
10. `Pass` 后焊缝能映射；
11. 有硬件时验证相机连接与采集；
12. 有硬件时验证机械臂连接、状态监控与扫描；
13. 按 `docs/calibration/README.md` 第 3.2 节核对手眼标定；
14. 用“移动至焊缝起点上方”和“焊缝空走”核对轨迹。
