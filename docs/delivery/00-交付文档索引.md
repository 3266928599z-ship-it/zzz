# dianyun 项目交付文档

## 1. 文档目的

本目录用于交付 `dianyun` 三维工件处理软件的源代码、构建方法、使用流程、算法原理、测试依据和维护边界。

文档面向以下人员：

- 第一次接触本项目的 C++/Qt 开发人员；
- 负责部署 Visual Studio、Qt、PCL 和海康 MVS SDK 的工程人员；
- 负责验证模型匹配和焊缝映射结果的测试人员；
- 后续继续开发点云处理、模型匹配或焊缝规划功能的算法人员。

阅读完本套文档后，接手者应能够：

1. 理解软件当前能做什么、不能做什么；
2. 找到每项功能对应的源代码；
3. 在满足依赖条件的 Windows 计算机上编译项目；
4. 导入 STEP 与 PLY/PCD，完成模型匹配、焊缝创建和焊缝映射；
5. 理解配准矩阵方向、各质量指标和判定门槛；
6. 根据日志定位常见故障；
7. 在不破坏线程安全和坐标约定的前提下继续开发。

## 5. 五分钟快速上手

1. 打开 `dianyun/dianyun.sln`。
2. 确认 Visual Studio 为 `Release | x64`。
3. 确认 Qt VS Tools 中存在名为 `6.10.1_msvc2022_64` 的 Qt 版本。
4. 检查 `dianyun/dianyun/dianyun.vcxproj` 中的 vcpkg、PCL 和 MVS SDK 路径。
5. 生成解决方案并运行 `dianyun`。
6. 点击“导入三维模型”，选择 STEP/STP。
7. 点击“导入点云模型”，选择 PLY/PCD，等待完整点云显示完成。
8. 点击“模型匹配”，等待状态变为“匹配通过”或“需要人工确认”。
9. 若需要焊缝：点击“新建焊缝”，按住 `Ctrl` 依次单击两个不同 CAD 面。
10. 在焊缝列表选择焊缝；只有最新模型匹配“通过”时，“焊缝映射”按钮才可用。

详细步骤见 [03-编译与使用指南](03-编译与使用指南.md)。

## 6. 接手前必须理解的四个约定

### 6.1 单位约定

程序不做自动单位转换。CAD、点云、相机标定参数和最终残差必须使用同一长度单位。当前参数命名和相机默认值按毫米理解。

### 6.2 变换方向

模型匹配内部主要计算：

```text
扫描点云坐标 -> CAD 坐标
```

最终输出：

```text
T_final：CAD 坐标 -> 扫描点云坐标
```

焊缝映射必须使用 `T_final`，不能误用其逆矩阵。

### 6.3 匹配与焊缝映射的关系

模型匹配不依赖焊缝。焊缝映射是匹配完成后的独立步骤，并且仅允许对判定为 `Pass` 的最新匹配结果执行。

### 6.4 点云显示与匹配数据

导入的完整点云会保留在内存中，并以每批 100000 点渐进显示。模型匹配内部会另行体素降采样，显示全部点不等于配准使用全部原始点。

## 7. 文档维护规则

发生以下修改时，必须同步更新交付文档：

- 修改 `MatchConfig` 或 `classifyResult()` 中的阈值；
- 修改 `T_final` 的方向或坐标定义；
- 增删 UI 按钮、文件格式或操作步骤；
- 修改 Qt、PCL、OpenCascade、VTK 或 MVS SDK 版本；
- 增加新的工作线程、异步任务或共享数据；
- 修改焊缝表示、映射方式或显示颜色；
- 新增自动测试、测试数据或验收门槛；
- 推送新的正式交付提交。
