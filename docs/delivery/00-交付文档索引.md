# dianyun 项目交付文档

## 1. 文档目的

本目录用于交付 `dianyun` 焊接视觉系统的源代码、构建方法、使用流程、算法原理、测试依据和维护边界。软件涵盖三维工件处理、线激光扫描采集、法奥机械臂联动和焊缝轨迹执行。

文档面向以下人员：

- 第一次接触本项目的 C++/Qt 开发人员；
- 负责部署 Visual Studio、Qt、PCL、海康 Mv3dLp SDK 和法奥机械臂 SDK 的工程人员；
- 负责验证模型匹配和焊缝映射结果的测试人员；
- 负责现场标定、扫描和机械臂联调的现场人员；
- 后续继续开发点云处理、模型匹配或焊缝规划功能的算法人员。

阅读完本套文档后，接手者应能够：

1. 理解软件当前能做什么、不能做什么；
2. 找到每项功能对应的源代码；
3. 在满足依赖条件的 Windows 计算机上编译项目；
4. 导入 STEP 与 PLY/PCD，完成模型匹配、焊缝创建和焊缝映射；
5. 连接相机与机械臂，完成扫描采集和焊缝轨迹执行；
6. 理解配准矩阵方向、各质量指标和判定门槛；
7. 根据日志定位常见故障；
8. 在不破坏线程安全和坐标约定的前提下继续开发。

## 5. 五分钟快速上手

1. 打开 `dianyun/dianyun.sln`。
2. 确认 Visual Studio 为 `Release | x64`。
3. 确认 Qt VS Tools 中存在名为 `6.10.1_msvc2022_64` 的 Qt 版本。
4. 检查 `dianyun/dianyun/dianyun.vcxproj` 中的 vcpkg、PCL 路径；Mv3dLp 与法奥 SDK 已在 `dianyun/third_party/` 下，无需另行安装。
5. 生成解决方案并运行 `dianyun`（构建后会自动执行 `DeployQtRuntime` 与 `DeployFairinoRuntime`）。
6. 点击“导入三维模型”，选择 STEP/STP。
7. 点击“导入点云模型”，选择 PLY/PCD，等待完整点云显示完成；或在“通信”菜单连接相机与机械臂后，用“执行 → 开始扫描采集”获取基坐标点云。
8. 点击“模型匹配”，等待状态变为“匹配通过”或“匹配质量不足”。
9. 若需要焊缝：点击“新建焊缝”，按住 `Ctrl` 依次单击两个不同 CAD 面；再用“设定起点”“反转方向”确定焊接方向。
10. 在焊缝列表选择焊缝；只有最新模型匹配“通过”时，“焊缝映射”按钮才可用。
11. 若需机械臂执行：先确认 `calibration.json` 有效，再依次使用“移动至焊缝起点上方”和“焊缝空走”核对，最后“沿焊缝执行”。

详细步骤见 [03-编译与使用指南](03-编译与使用指南.md)。

## 6. 接手前必须理解的五个约定

### 6.1 单位约定

程序不做自动单位转换。CAD、点云、相机标定参数和最终残差必须使用同一长度单位。当前参数命名和相机默认值按毫米理解。

### 6.2 变换方向

模型匹配内部主要计算：

```text
扫描点云坐标 -> CAD 坐标
```

最终输出：

```text
T_final：CAD 坐标 -> 扫描点云坐标
```

焊缝映射必须使用 `T_final`，不能误用其逆矩阵。

### 6.3 匹配与焊缝映射的关系

模型匹配不依赖焊缝。焊缝映射是匹配完成后的独立步骤，并且仅允许对判定为 `Pass` 的最新匹配结果执行。`Pass` 之外只剩 `Fail`；多解歧义和点到面 ICP 未收敛只在日志中提示，需要人工复核对齐 CAD。

### 6.4 点云显示与匹配数据

导入的完整点云会保留在内存中，并以每批 100000 点渐进显示。模型匹配内部会另行体素降采样，显示全部点不等于配准使用全部原始点。

### 6.5 点云坐标系与机械臂执行

点云分为两种坐标系（`CloudFrame`）：

- `Sensor`：传感器坐标，来自文件导入、单帧拍摄或轨迹不足时的回退拼接；
- `RobotBase`：机器人基坐标，来自加载了有效手眼标定的扫描采集。

只有 `RobotBase` 点云的匹配和焊缝映射结果才能生成轨迹并下发机械臂。此时 `T_final` 为 CAD -> 基坐标。

手眼标定存放在 exe 同目录 `calibration.json`，详见 `../calibration/README.md`。注意工具坐标 Z 为 250 mm，外参 tz 必须扣除工具长。

## 7. 文档维护规则

发生以下修改时，必须同步更新交付文档：

- 修改 `MatchConfig` 或 `classifyResult()` 中的阈值；
- 修改 `T_final` 的方向或坐标定义；
- 增删 UI 按钮、文件格式或操作步骤；
- 修改 Qt、PCL、OpenCascade、VTK、Mv3dLp 或法奥 SDK 版本；
- 增加新的工作线程、异步任务或共享数据；
- 修改焊缝表示、映射方式、起点/方向语义或显示颜色；
- 修改手眼标定参数、工具坐标或扫描姿态；
- 修改轨迹规划参数（接近高度、安全余量、返回逻辑）；
- 增删菜单项或执行流程；
- 新增自动测试、测试数据或验收门槛；
- 推送新的正式交付提交。
