# 配置参数说明

## 1. 参数管理现状

当前参数主要以 C++ 默认值和局部常量存在。唯一的外部配置文件是 exe 同目录的 `calibration.json`（手眼标定，见第 17 节），其余参数没有配置文件或设置界面。

参数来源：

- `MatchTypes.h::MatchConfig`；
- `HikCameraWorker.h::ScanParams`；
- `ScanController.h::ScanRequest` 及 `ScanController.cpp` 局部常量；
- `HandEyeConfig.h`；
- `WeldPathPlanner.h::WeldPathOptions`；
- `dianyun.cpp` 中扫描位姿、接近高度、空走抬高等局部常量；
- `StepModelLoader.cpp`；
- `ModelMatchWorker.cpp`；
- `VisualizationManager.cpp`。

修改参数后需要重新编译（`calibration.json` 除外，可通过菜单“通信 → 重新加载手眼标定”生效）。

## 2. 参数调整原则

1. 先确认 CAD 与点云单位一致。
2. 先保留原始测试数据和基准结果。
3. 一次只修改一类参数。
4. 同时记录成功率、耗时、RMSE、P95 和覆盖率。
5. 不要只针对单个角度调参。
6. 修改判定门槛前建立更多真实用例。
7. 参数变更应通过 Git 提交并更新本文档。

## 3. 模型匹配公开参数

位置：`MatchTypes.h`。

| 参数 | 默认值 | 含义 | 调大影响 | 调小影响 |
| --- | ---: | --- | --- | --- |
| `leafSizeFactor` | 0.01 | CAD 对角线到体素尺寸的比例 | 更快、更粗、细节减少 | 更慢、更细、内存增加 |
| `edgePercentile` | 0.25 | 保留高显著性点比例 | 特征点更多、计算更慢 | 特征更集中，可能不足 |
| `sacRuns` | 8 | FPFH-SAC 随机运行次数 | 候选更多、成功率和耗时增加 | 更快但可能漏解 |
| `sacInlierFrac` | 0.15 | SAC 内点比例 | 更严格，残缺点云可能失败 | 更宽松，假候选增多 |
| `ambiguityRatio` | 1.10 | 第二候选/第一候选分数歧义阈值 | 更容易判为歧义（仅影响日志提示，不再改变判定） | 更少歧义提示，风险增加 |
| `icpMaxIterA` | 50 | 点到点 ICP 最大迭代 | 更充分但更慢 | 可能未收敛 |
| `icpMaxIterB` | 50 | 点到面 ICP 最大迭代 | 更充分但更慢 | 可能未收敛 |
| `scanUpAxis` | `(0, 0, 1)` | 扫描点云坐标系中朝向相机（向上）的方向，用于支撑平面判定 | — | — |

`scanUpAxis` 说明：海康线激光离相机越近 Z 越大，故传感器坐标取 +Z；基坐标点云下为基座竖直向上方向。本机落地安装、基座 +Z 朝上，两种坐标系恰好都取 `UnitZ`。改变安装方式（如倒装、侧装）时必须同步修改，否则支撑平面会被误判。

### 3.1 实际体素尺寸

```text
leaf = max(CAD_diagonal * leafSizeFactor, 0.5)
```

示例：

| CAD 对角线 | 比例 | 计算值 | 最终 leaf |
| ---: | ---: | ---: | ---: |
| 40 | 0.01 | 0.4 | 0.5 |
| 100 | 0.01 | 1.0 | 1.0 |
| 200 | 0.01 | 2.0 | 2.0 |

## 4. CAD 导入参数

位置：`StepModelLoader.cpp`。

| 参数/公式 | 当前值 | 作用 |
| --- | --- | --- |
| 线性三角化偏差 | `max(diagonal * 0.001, 0.01)` | 控制显示网格精度 |
| 三角化角度 | `0.5 rad` | 控制曲面三角化 |
| 表面采样间距 | `max(diagonal * 0.005, 0.25)` | 控制 CAD 配准点密度 |
| 每三角形最少采样 | 1 | 避免小三角形无点 |
| 每三角形最多采样 | 1000 | 限制极大面开销 |

调参风险：

- 采样太稀会丢失小孔、台阶和圆弧；
- 采样太密会增加内存和预处理时间；
- 三角化偏差太大只影响网格和拾取精度，也可能影响面映射显示。

## 5. 扫描预处理参数

### 5.1 支撑平面剔除

处理顺序为：体素降采样 → SOR → 支撑平面剔除 → 欧式聚类。

| 参数 | 值 |
| --- | ---: |
| 最多尝试平面数 | 4 |
| 模型 | `SACMODEL_PERPENDICULAR_PLANE`，法向与 `scanUpAxis` 夹角 ≤ 30° |
| 最大迭代 | 500 |
| 距离阈值 | `1.25 * leaf` |
| 候选平面最少点数 | `max(50, 5% 点数)` |
| 启用最低点数 | 200 |
| 平面下方点判定 | 有符号距离 `< -1.5 * leaf` |
| 平面上方点判定 | 有符号距离 `> 2.0 * leaf` |
| 支撑面条件 | 下方点比例 `< 2%` 且上方点比例 `>= 5%` |
| 多个支撑面时 | 取高度（沿 `scanUpAxis`）最低者 |
| 剔除范围 | 距离平面 `> 1.25 * leaf` 的上方点保留，其余删除 |
| 剔除后最低剩余点 | 100 |
| 误删回退 | 剔除后主体尺寸比 `< 0.45`，且未剔除的主体尺寸比在 0.45~1.35 内，则回退 |

旧版本使用“最大平面且占比 > 0.15”，已被上述单侧性判定取代：最大平面可能就是工件顶面，而底板一定几乎无点在其下方。

| 参数 | 值 |

## 11. 质量判定参数

判定只有 `Pass` 和 `Fail` 两种。`NeedsReview` 已移除。

### 11.1 Fail

| 指标 | Fail 条件 |
| --- | --- |
| 扫描覆盖 | `< 0.30` |
| CAD 支持 | `< 0.10` |
| 特征覆盖 | `< 0.15` |
| 空间覆盖 | `< 0.18` |
| 法向一致 | `< 0.45` |
| RMSE | 非有限或 `> 1.25 * leaf` |
| P95 | `> 2.0 * leaf` |

不触发以上任一条件即为 `Pass`。

### 11.2 不再阻断的情形

以下情形原先判为 `NeedsReview`、不允许焊缝映射，现在只写日志，不影响 `Pass`：

| 指标 | 原条件 |
| --- | --- |
| 多解 | `wasAmbiguous == true` |
| 点到面收敛 | false |
| 扫描覆盖 | `< 0.55` |
| CAD 支持 | `< 0.25` |
| 特征覆盖 | `< 0.35` |
| 空间覆盖 | `< 0.40` |
| 法向一致 | `< 0.70` |

注意：这意味着对称工件可能在存在多解时直接 `Pass`。现场必须依据对齐 CAD 叠加效果人工复核，再进行焊缝映射和机械臂执行。

| `laserEnabled` | true | — | 采集期间是否点亮激光 |

### 12.2 扫描几何约束

```text
travelSpeedMmS = stepDistanceUm × lineRate / 1000
```

本机标定值：96 µm × 491 行/s ≈ 47 mm/s。三者不自洽时点云 Y 向会被均匀拉伸或压缩。

设备行为（实机探针确认，MV-DP2240-01H，SDK 1.3.3.3）：

- `ImageMode = 4` 输出 `Profile/ABC16`（3×int16），不是 float 点云；
- `AcquisitionFrameRate` 控制的是轮廓行率；设定 600 Hz 实测约 491 行/s，设备上限约 1120 行/s；
- 回调中的 `fXScale/fYScale/fZScale` 恒为 0，换算只能用 `LSLProfileCoordXUnit/ZUnit`（本机 4.0 µm/count）；
- 空点三个分量同为 -32768。

### 12.3 点坐标公式

```text
x_mm = A × LSLProfileCoordXUnit / 1000
z_mm = C × LSLProfileCoordZUnit / 1000
y_mm = 全局行序号 × stepUm / 1000      （按行序号补 Y）
```

轨迹模式下，Y 改由每行采集时刻在机器人实测轨迹上插值得到的行进距离给出，不再依赖“步距 × 行率 = 速度”。

## 12D. 手眼标定（`calibration.json`）

位置：exe 同目录，首次运行自动生成模板，格式：

```json
{
  "handEye": { "tx": 42.52, "ty": 88.47, "tz": 41.82, "rx": -3.122, "ry": -0.027, "rz": 1.584 },
  "sensorAxis": [[0, 1, 0], [1, 0, 0], [0, 0, -1]],
  "timeOffsetUs": 0
}
```

- 外参为工具 1 → 传感器，固定轴 XYZ，mm / 度；
- `sensorAxis` 必须是行列式为 +1 的正交矩阵；
- `timeOffsetUs`：正值表示行实际更晚采集，正反两向各扫一次，调到点云重合；
- 代码中的编译期默认值（`HandEyeConfig.h`）为 HiCalibrator 原始输出 `tz = 290.166`，**未扣工具长**，仅用于文件不存在时生成模板。现场 `tz` 必须按 `docs/calibration/README.md` 扣除工具长（工具 Z 为 250 mm）；
- 完整修正记录见 `docs/calibration/README.md` 第 3 节。

## 15. 推荐调参流程

### 场景 A：粗配准经常无候选

依次尝试：

1. 检查单位；
2. 检查预处理主体；
3. 将 `sacRuns` 从 8 增至 12 或 16；
4. 将 `sacInlierFrac` 从 0.15 降至 0.10；
5. 将 `edgePercentile` 从 0.25 增至 0.30；
6. 不要先放宽最终质量门槛。

### 场景 B：匹配很慢

依次尝试：

1. 增大 `leafSizeFactor`；
2. 减少 `sacRuns`；
3. 降低 `icpMaxIterA/B`；
4. 检查点云中底板是否被正确剔除；
5. 增加耗时日志后再优化。

### 场景 C：局部对齐但整体错误

优先：

1. 提高空间覆盖要求；
2. 提高特征覆盖权重；
3. 检查自动裁剪是否只保留局部平面；
4. 保留更多不同粗候选；
5. 不要单纯增大 ICP 迭代数。

### 场景 D：正确结果被判为人工确认

先分析是哪项指标不足。只有在多组真实样本均证明阈值过严时，才调整 `classifyResult()`。
