# 配置参数说明

## 1. 参数管理现状

当前参数主要以 C++ 默认值和局部常量存在，没有外部配置文件或设置界面。

参数来源：

- `MatchTypes.h::MatchConfig`；
- `HikCameraWorker.h::ScanParams`；
- `HikCameraWorker` 构造函数；
- `StepModelLoader.cpp`；
- `ModelMatchWorker.cpp`；
- `VisualizationManager.cpp`。

修改参数后需要重新编译。

## 2. 参数调整原则

1. 先确认 CAD 与点云单位一致。
2. 先保留原始测试数据和基准结果。
3. 一次只修改一类参数。
4. 同时记录成功率、耗时、RMSE、P95 和覆盖率。
5. 不要只针对单个角度调参。
6. 修改判定门槛前建立更多真实用例。
7. 参数变更应通过 Git 提交并更新本文档。

## 3. 模型匹配公开参数

位置：`MatchTypes.h`。

| 参数 | 默认值 | 含义 | 调大影响 | 调小影响 |
| --- | ---: | --- | --- | --- |
| `leafSizeFactor` | 0.01 | CAD 对角线到体素尺寸的比例 | 更快、更粗、细节减少 | 更慢、更细、内存增加 |
| `edgePercentile` | 0.25 | 保留高显著性点比例 | 特征点更多、计算更慢 | 特征更集中，可能不足 |
| `sacRuns` | 8 | FPFH-SAC 随机运行次数 | 候选更多、成功率和耗时增加 | 更快但可能漏解 |
| `sacInlierFrac` | 0.15 | SAC 内点比例 | 更严格，残缺点云可能失败 | 更宽松，假候选增多 |
| `ambiguityRatio` | 1.10 | 第二候选/第一候选分数歧义阈值 | 更容易判为歧义 | 更少人工确认，风险增加 |
| `icpMaxIterA` | 50 | 点到点 ICP 最大迭代 | 更充分但更慢 | 可能未收敛 |
| `icpMaxIterB` | 50 | 点到面 ICP 最大迭代 | 更充分但更慢 | 可能未收敛 |

### 3.1 实际体素尺寸

```text
leaf = max(CAD_diagonal * leafSizeFactor, 0.5)
```

示例：

| CAD 对角线 | 比例 | 计算值 | 最终 leaf |
| ---: | ---: | ---: | ---: |
| 40 | 0.01 | 0.4 | 0.5 |
| 100 | 0.01 | 1.0 | 1.0 |
| 200 | 0.01 | 2.0 | 2.0 |

## 4. CAD 导入参数

位置：`StepModelLoader.cpp`。

| 参数/公式 | 当前值 | 作用 |
| --- | --- | --- |
| 线性三角化偏差 | `max(diagonal * 0.001, 0.01)` | 控制显示网格精度 |
| 三角化角度 | `0.5 rad` | 控制曲面三角化 |
| 表面采样间距 | `max(diagonal * 0.005, 0.25)` | 控制 CAD 配准点密度 |
| 每三角形最少采样 | 1 | 避免小三角形无点 |
| 每三角形最多采样 | 1000 | 限制极大面开销 |

调参风险：

- 采样太稀会丢失小孔、台阶和圆弧；
- 采样太密会增加内存和预处理时间；
- 三角化偏差太大只影响网格和拾取精度，也可能影响面映射显示。

## 12. 相机参数

位置：`HikCameraWorker.h/.cpp`。

### 12.1 有效运行时默认值

头文件结构体提供初始值，但构造函数会覆盖部分参数。当前对象构造后的有效值：

| 参数 | 有效默认值 | 单位 | 是否参与计算 |
| --- | ---: | --- | --- |
| `runSpeed` | 1.0 | mm/s | 当前未使用 |
| `xRes` | 0.096 | mm/像素或设备标定单位 | 是 |
| `yRes` | 0.096 | mm/行 | 是 |
| `targetLen` | 50.0 | mm | 是 |
| `zScale` | 100.0 | 原始值缩放 | 是 |

注意：`ScanParams` 声明中的 `targetLen = 10.0` 会被构造函数改为 50.0。建议后续只保留一个默认值来源。

### 12.2 点坐标公式

```text
x = (rawX - width / 2) * xRes
y = frameCount * yRes
z = rawZ / zScale
```

目标帧数：

```text
targetFrames = max(1, int(targetLen / yRes))
```

### 12.3 原始值过滤

```text
-30000 < rawZ < 30000
```

像素格式固定检查：

```text
0x022000BB
```

不同相机型号必须确认该格式。

## 15. 推荐调参流程

### 场景 A：粗配准经常无候选

依次尝试：

1. 检查单位；
2. 检查预处理主体；
3. 将 `sacRuns` 从 8 增至 12 或 16；
4. 将 `sacInlierFrac` 从 0.15 降至 0.10；
5. 将 `edgePercentile` 从 0.25 增至 0.30；
6. 不要先放宽最终质量门槛。

### 场景 B：匹配很慢

依次尝试：

1. 增大 `leafSizeFactor`；
2. 减少 `sacRuns`；
3. 降低 `icpMaxIterA/B`；
4. 检查点云中底板是否被正确剔除；
5. 增加耗时日志后再优化。

### 场景 C：局部对齐但整体错误

优先：

1. 提高空间覆盖要求；
2. 提高特征覆盖权重；
3. 检查自动裁剪是否只保留局部平面；
4. 保留更多不同粗候选；
5. 不要单纯增大 ICP 迭代数。

### 场景 D：正确结果被判为人工确认

先分析是哪项指标不足。只有在多组真实样本均证明阈值过严时，才调整 `classifyResult()`。

后续建议增加：

```text

└─ matching.json
```

按功能分组：

- preprocessing；
- feature；
- coarse_registration；
- guided_crop；
- icp；
- quality；
- camera；
- visualization。

要求：

- 启动时校验范围；
- 日志记录实际参数；
- 测试报告记录配置版本；
- 保留代码默认值作为安全回退。
